# 面试 BOSS 攻略

> 面试造火箭，工作拧螺丝。这里把各技术栈的"八股文"整理成册——不是让你死记硬背答案，而是帮你把高频考点背后的原理真正啃明白。

## 板块特点

- **高频考点**：只收录面试中反复出现的经典问题
- **由浅入深**：先答结论，再拆原理，最后给延伸问题
- **考点串联**：把零散知识点串成体系，面试官怎么追问都不慌
- **持续更新**：紧跟各技术栈的面试风向

## 覆盖方向

- **前端八股** - JavaScript/TypeScript 原理、框架源码、浏览器与网络
- **后端八股** - 框架原理、并发编程、JVM/GC、内存模型
- **编程语言** - Java、Python、Go、C++ 语言特性与底层机制
- **数据库** - 索引与 SQL 优化、事务与锁、分库分表
- **计算机网络** - TCP/UDP、HTTP/HTTPS、DNS、WebSocket
- **操作系统** - 进程线程、内存管理、文件系统、Linux 常用机制
- **系统设计** - 高并发、缓存、消息队列、分布式一致性

## 使用方法

1. **先自测** - 看到题目先在心里作答，别急着看解析
2. **再对照** - 对照解析找知识盲区，而不是背"标准答案"
3. **多追问** - 每个考点都想一想"面试官还能往哪深挖"
4. **动手验证** - 原理类问题最好写段代码亲自验证一遍
