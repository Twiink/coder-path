# Claude Code 学习路线

Claude Code，Anthropic 官方的 AI 编程助手。从代码生成到重构优化，从 Bug 调试到架构设计，Claude Code 让 AI 辅助编程变得强大而高效。学会它，你就掌握了 AI 时代的编程技能。

## 为什么学 Claude Code

- 官方 CLI 工具，与 Claude 深度集成
- 支持 MCP 协议，可扩展能力极强
- 理解上下文能力强，代码质量高
- 支持多文件编辑，重构能力出色
- Workflows 自动化，提升开发效率

## 提示词技巧

**清晰描述**
- ✅ "实现一个 JWT 认证中间件，支持 token 刷新"
- ❌ "做个认证"

**提供上下文**
- ✅ "这是 Express 项目，使用 TypeScript"
- ❌ 不说明技术栈

**指定约束**
- ✅ "保持现有代码风格，不要改动其他文件"
- ❌ 没有明确边界

**分步执行**
- ✅ "先实现基础功能，再添加错误处理"
- ❌ 一次要求所有功能

掌握 Claude Code，你就掌握了 AI 辅助编程的精髓。从代码生成到系统设计，从 Bug 修复到性能优化，Claude Code 让开发变得更加高效和智能。别把 AI 当作魔法，它是工具，需要你清晰地表达需求。先从简单的代码生成开始，慢慢探索它的能力边界。记住：AI 生成的代码要审查，测试不能省。多实践，多探索，Claude Code 会成为你最强大的编程伙伴。
