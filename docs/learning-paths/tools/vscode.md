# VS Code 学习路线

VS Code，微软开源的现代化编辑器。轻量快速，功能强大，插件丰富，支持几乎所有编程语言。学会它，你的编码效率会翻倍。

## 为什么学 VS Code

- 免费开源，跨平台支持
- 启动快速，占用资源少
- 内置 Git 支持，调试功能强大
- 插件生态丰富，可定制性强
- 智能代码补全，开发体验极佳

## 学习路线图

### 第一阶段：基础使用

**安装配置**
- macOS / Linux / Windows 安装
- code 命令行工具
- 基础界面认识
- 侧边栏功能
- 命令面板（Cmd/Ctrl+Shift+P）

**快捷键**
- Cmd/Ctrl+P 快速打开文件
- Cmd/Ctrl+Shift+P 命令面板
- Cmd/Ctrl+B 切换侧边栏
- Cmd/Ctrl+J 切换终端
- Cmd/Ctrl+\ 分割编辑器

**文件操作**
- 新建文件/文件夹
- 打开文件夹
- 工作区概念
- 文件树操作
- 搜索文件（Cmd/Ctrl+P）

**编辑技巧**
- 多光标编辑（Alt+Click）
- 列选择（Shift+Alt+拖动）
- 移动行（Alt+↑/↓）
- 复制行（Shift+Alt+↑/↓）
- 删除行（Cmd/Ctrl+Shift+K）

## 常用快捷键（macOS）

**通用**
- `Cmd+P`：快速打开文件
- `Cmd+Shift+P`：命令面板
- `Cmd+,`：打开设置
- `Cmd+B`：切换侧边栏
- `Cmd+J`：切换终端

**编辑**
- `Cmd+D`：选择下一个匹配
- `Cmd+L`：选择整行
- `Alt+↑/↓`：移动行
- `Shift+Alt+↑/↓`：复制行
- `Cmd+/`：注释切换

掌握 VS Code，你的编码效率会翻倍。从基础的编辑到高级的调试，从本地开发到远程协作，VS Code 让编程变得更加高效和愉悦。别被海量插件淹没，先把基础功能用熟，再慢慢探索插件生态。快捷键看起来多，但常用的就那么几个。多实践，多探索，VS Code 会成为你最强大的开发工具。
