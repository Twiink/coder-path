# 微信小程序学习路线

腾讯出品的轻量级应用，微信生态内的流量入口。无需下载安装，用完即走。10 亿+ 月活用户，触达能力强。前端技术栈，学习成本低。适合快速验证产品，获取微信生态流量。

## 为什么学微信小程序

微信是国民级应用，小程序是微信生态的重要组成部分。开发门槛低，审核快，分发成本低。适合电商、工具、内容等各类场景。学会小程序开发，相当于掌握了一个巨大的流量入口。语法类似前端，但有自己的特色。组件化开发，双线程架构，性能优于 H5。配合微信支付、分享、登录等能力，能快速构建完整的商业应用。

## 学习路线图

### 基础篇：框架与组件

- **开发环境搭建**：注册小程序账号、安装开发者工具、创建项目
- **项目结构**：pages 页面、components 组件、app 配置
- **WXML 模板**：数据绑定、列表渲染、条件渲染、模板复用
- **WXSS 样式**：rpx 单位、样式继承、选择器限制
- **JavaScript 逻辑**：页面生命周期、数据操作、事件处理

### 进阶篇：API 与功能

- **组件系统**：视图容器、基础内容、表单组件、媒体组件
- **路由导航**：页面跳转、参数传递、返回处理、tabBar 配置
- **API 调用**：网络请求、数据存储、交互反馈、媒体选择
- **自定义组件**：组件定义、属性传递、事件触发、生命周期

### 实战篇：进阶与发布

- **登录与授权**：微信登录、获取用户信息、授权管理
- **微信支付**：支付接口、订单管理、退款处理
- **性能优化**：数据更新优化、长列表优化、图片优化
- **云开发**：云函数、云数据库、云存储（可选）
- **发布流程**：填写信息、配置域名、提交审核、版本管理

## 下一步学习

完成基础路线后，可以深入探索：

- **云开发**：无需后端的开发模式
- **小程序插件**：复用和分享功能
- **分包加载**：优化小程序性能
- **自定义 tabBar**：个性化底部导航
- **小程序直播**：直播功能集成
