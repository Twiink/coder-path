# Android 原生开发学习路线

Google 的亲儿子，移动开发的半壁江山。从 Java 走到 Kotlin，从 XML 走到 Jetpack Compose，Android 开发越来越现代化。掌握原生开发，就能用 Kotlin 配合 Jetpack 全家桶，构建流畅的原生应用。

## 为什么选择 Android 原生开发

市场占有率高，全球超过 70% 的移动设备运行 Android。原生开发直接访问系统 API，性能和体验都是最佳的。Kotlin 语言优雅，空安全、扩展函数、协程样样俱全。配合 Jetpack Compose 声明式 UI，告别繁琐的 XML，开发效率直线上升。

跨平台方案省事，但遇到复杂场景，原生永远是最靠谱的选择。学会 Android 原生，你就掌握了移动开发的硬通货。

## 学习路线图

### 基础篇：环境与语言

- **开发环境搭建**：Android Studio 安装、SDK 配置、模拟器设置
- **Kotlin 语言基础**：变量类型、函数、类与对象、空安全特性
- **Kotlin 进阶**：扩展函数、高阶函数、集合操作、协程异步编程
- **项目结构**：Gradle 构建、清单文件、资源管理

### 进阶篇：UI 与架构

- **Jetpack Compose 基础**：声明式 UI、组件系统、布局容器
- **状态管理**：remember、State、ViewModel、Flow
- **导航系统**：Navigation Compose、参数传递、返回栈管理
- **Jetpack 组件**：ViewModel、LiveData/Flow、Room 数据库、WorkManager

### 实战篇：功能与发布

- **网络请求**：Retrofit、Coroutines、请求拦截、错误处理
- **本地存储**：SharedPreferences、Room、DataStore
- **多媒体**：图片加载（Coil）、相机、音视频播放
- **权限管理**：运行时权限、系统能力调用
- **性能优化**：内存管理、布局优化、启动速度优化
- **打包发布**：签名配置、混淆规则、Google Play 上架

## 下一步学习

完成基础路线后，可以深入探索：

- **Kotlin Multiplatform**：跨平台共享代码
- **Jetpack Compose for Desktop**：桌面应用开发
- **Material Design 3**：设计系统深度应用
- **Android TV / Wear OS**：扩展到其他 Android 平台
- **CI/CD**：自动化构建与发布流程
