# React Native 学习路线

Facebook 出品的跨平台移动开发框架，用 JavaScript 写 iOS 和 Android 应用。不是 WebView 套壳，而是真正的原生组件渲染。一套代码，两个平台，开发效率翻倍。React 开发者的福音，Web 技能直接迁移到移动端。

## 为什么选择 React Native

如果你已经会 React，学习 React Native 几乎零成本。组件、状态、Hooks、生态工具都是同一套。跨平台开发省时省力，代码复用率高，维护成本低。虽然性能不如原生，但对大多数应用来说足够了。热更新、快速迭代、庞大的社区生态，这些都是 React Native 的优势。

## 学习路线图

### 基础篇：环境与组件

- **开发环境搭建**：Node.js、Xcode/Android Studio、依赖安装
- **React Native 基础**：核心组件（View、Text、Image）、样式系统
- **布局系统**：Flexbox 布局、尺寸单位、响应式设计
- **触摸事件**：Touchable 系列、Pressable、手势处理
- **列表组件**：FlatList、SectionList、性能优化

### 进阶篇：导航与状态

- **导航系统**：React Navigation、栈导航、标签导航、抽屉导航
- **状态管理**：Context API、Zustand、Redux Toolkit
- **网络请求**：fetch、Axios、请求拦截、错误处理
- **本地存储**：AsyncStorage、MMKV、数据持久化

### 实战篇：功能与发布

- **UI 组件库**：React Native Paper、NativeBase、自定义组件
- **图片选择**：react-native-image-picker、相机调用
- **性能优化**：列表优化、避免不必要渲染、图片优化
- **原生模块集成**：调用原生代码、第三方 SDK 集成
- **打包发布**：iOS 发布流程、Android 打包签名、上架应用商店

## 下一步学习

完成基础路线后，可以深入探索：

- **React Native Reanimated**：高性能动画
- **React Native Gesture Handler**：手势处理
- **Expo**：快速开发工具
- **CodePush**：热更新
- **Hermes**：JavaScript 引擎优化

---

React Native 让 Web 开发者无缝进入移动开发，一套代码跑两个平台，开发效率极高。虽然性能不如原生，但对大多数应用足够了。庞大的社区和丰富的第三方库是最大的优势。记住：跨平台是效率和性能的权衡，选择适合自己的方案。加油！
