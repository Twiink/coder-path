# uni-app 学习路线

DCloud 出品的跨平台框架，一套代码生成 iOS、Android、H5、小程序（微信、支付宝、百度、字节跳动等）。基于 Vue.js 语法，上手快。国内生态好，中文文档完善，适合快速开发多端应用。

## 为什么选择 uni-app

如果你需要同时覆盖 App 和小程序，uni-app 是最优选择。一套代码，十几个平台，真正的"一次编写，到处运行"。国内企业用得多，招聘需求大。Vue 开发者几乎零学习成本，语法熟悉。官方组件和 API 丰富，开箱即用。插件市场资源多，很多现成的轮子可以用。

## 学习路线图


### 基础篇：框架与语法

- **开发环境搭建**：HBuilderX 安装、Vue CLI 模式、项目创建
- **项目结构**：pages 页面、components 组件、static 静态资源
- **WXML 模板语法**：数据绑定、列表渲染、条件渲染、模板引用
- **WXSS 样式**：rpx 单位、样式继承、平台差异

### 进阶篇：组件与路由

- **基础组件**：视图容器、基础内容、表单组件、导航组件
- **路由与导航**：页面配置、页面跳转、参数传递、返回处理
- **生命周期**：应用生命周期、页面生命周期、下拉刷新、上拉加载
- **API 调用**：网络请求、数据存储、媒体选择、位置服务

### 实战篇：功能与发布

- **状态管理**：Vuex、Pinia、全局数据共享
- **条件编译**：平台差异处理、多端适配、代码复用
- **UI 组件库**：uView UI、uni-ui、自定义组件
- **性能优化**：长列表优化、图片优化、减少 setData 调用
- **打包发布**：H5 发布、小程序发布、App 云打包

## 下一步学习

完成基础路线后，可以深入探索：
