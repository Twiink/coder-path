# iOS 原生开发学习路线

苹果的生态，优雅的设计，流畅的体验。iOS 开发从 Objective-C 走到 Swift，从 UIKit 走到 SwiftUI，越来越现代化。用 Swift 这门安全、简洁的语言，配合 SwiftUI 的声明式 UI，构建精致的原生应用。

## 为什么选择 iOS 原生开发

iOS 用户付费意愿高，应用生态质量好。虽然市场占有率不如 Android，但单个用户价值更高。设备碎片化程度低，适配简单，开发效率高。Swift 语言设计优雅，类型安全、协议导向、函数式编程，写起来很舒服。SwiftUI 的声明式 UI 让界面开发变得简单直观。

## 学习路线图

### 基础篇：环境与语言

- **开发环境搭建**：Xcode 安装、命令行工具、创建首个项目
- **Swift 语言基础**：变量常量、可选类型、集合类型、函数与闭包
- **Swift 进阶**：结构体与类、枚举、协议、扩展、泛型
- **异步编程**：async/await、Task、异步序列

### 进阶篇：UI 与架构

- **SwiftUI 基础**：视图系统、布局容器、修饰符
- **状态管理**：@State、@Binding、@StateObject、@ObservedObject、@EnvironmentObject
- **列表与导航**：List、LazyVStack、NavigationStack、导航传参
- **表单与输入**：TextField、SecureField、Picker、Toggle

### 实战篇：功能与发布

- **网络请求**：URLSession、async/await、JSON 解码、错误处理
- **数据持久化**：UserDefaults、Core Data、SwiftData
- **图片加载**：AsyncImage、Kingfisher 第三方库
- **权限管理**：相机、相册、位置等系统权限
- **性能优化**：懒加载、避免过度渲染、内存管理
- **发布流程**：签名配置、App Store Connect、TestFlight 测试

## 下一步学习

完成基础路线后，可以深入探索：

- **Combine**：响应式编程框架
- **SwiftUI Advanced**：高级布局和动画
- **App Clips**：轻量级应用体验
- **WidgetKit**：桌面小组件开发
- **CloudKit**：云端数据同步
- **StoreKit**：应用内购买
