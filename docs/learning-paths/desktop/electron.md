# Electron 学习路线

用 Web 技术构建桌面应用的框架，Chromium + Node.js 的组合。VSCode、Slack、Discord、Figma 都是用 Electron 开发的。前端技术栈，跨平台（Windows、macOS、Linux），开发效率高。

## 为什么选择 Electron

前端开发者零成本转桌面开发，HTML、CSS、JavaScript 直接上手。一套代码跑三个平台，维护成本低。生态成熟，插件丰富，能调用系统 API。虽然体积大、内存占用高，但对大多数应用来说不是问题。快速开发、跨平台、丰富的 UI 能力，这些优势远超劣势。

## 学习路线图

### 基础篇：架构与进程

- **开发环境搭建**：Node.js 安装、项目创建、依赖管理
- **应用架构**：主进程、渲染进程、预加载脚本
- **进程通信**：IPC 通信、contextBridge、安全隔离
- **窗口管理**：BrowserWindow、窗口配置、窗口事件

### 进阶篇：功能与集成

- **菜单系统**：应用菜单、右键菜单、快捷键绑定
- **对话框**：文件选择、保存对话框、消息框
- **文件操作**：读写文件、目录操作、路径处理
- **系统功能**：托盘图标、系统通知、原生功能调用

### 实战篇：优化与发布

- **自动更新**：electron-updater、版本检测、增量更新
- **前端框架集成**：React + Electron、Vue + Electron
- **打包发布**：electron-builder、多平台打包、安装包制作
- **性能优化**：减小包体积、优化启动速度、内存管理

## 下一步学习

完成基础路线后，可以深入探索：

- **Electron Forge**：现代化构建工具
- **Spectron**：自动化测试
- **electron-store**：数据持久化
- **electron-log**：日志管理
- **Native Node Modules**：原生模块集成

---

Electron 让前端开发者能用熟悉的技术栈构建桌面应用，开发效率高，跨平台能力强。虽然包体积大，但对大多数应用来说不是问题。VSCode 就是最好的证明。记住：性能优化很重要，合理使用进程通信。加油！
