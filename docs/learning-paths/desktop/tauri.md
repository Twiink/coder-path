# Tauri 学习路线

Rust + Web 技术的桌面应用框架，Electron 的轻量级替代品。包体积小（几 MB vs 几十 MB），内存占用低，性能更好。用 Rust 写后端，前端框架随意选（React、Vue、Svelte 都行）。新兴但发展迅速，值得关注。

## 为什么选择 Tauri

如果你觉得 Electron 太重，Tauri 是最佳替代。包体积小 10 倍，内存占用低，启动速度快。使用系统 WebView，不内嵌 Chromium，这是体积小的关键。Rust 写的后端，安全性高，性能好。前端用熟悉的 Web 技术，开发体验不输 Electron。跨平台（Windows、macOS、Linux），一套代码多端运行。

## 学习路线图

### 基础篇：环境与架构

- **开发环境搭建**：Rust 安装、依赖配置、项目创建
- **项目结构**：前端代码、Rust 后端、配置文件
- **Tauri 配置**：tauri.conf.json、窗口配置、权限白名单
- **命令系统**：定义命令、前端调用、参数传递、返回值处理

### 进阶篇：功能与 API

- **窗口管理**：window_manager、窗口操作、事件监听
- **文件系统**：file_picker、文件读写、目录操作
- **对话框**：文件选择、保存对话框、消息框
- **HTTP 请求**：Tauri HTTP API、请求拦截、CORS 处理
- **系统功能**：通知、系统托盘、快捷键、菜单栏

### 实战篇：集成与发布

- **事件系统**：Rust 发送事件、前端监听、双向通信
- **自动更新**：版本检测、下载更新、安装重启
- **打包发布**：配置图标、构建应用、多平台打包
- **性能优化**：Rust 优化、前端优化、包体积压缩

## 下一步学习

完成基础路线后，可以深入探索：

- **Rust 语言深入学习**：掌握后端开发
- **tauri-plugin-***：官方插件生态
- **Mobile Support**：移动端支持（开发中）
- **原生模块开发**：扩展功能
- **跨进程通信优化**：性能调优
