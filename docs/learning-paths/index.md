# 升级路线图

欢迎来到程序员的成长地图。这里不卖"21 天精通 XXX"的速成神话，也不画"学完年薪百万"的大饼——那种饼吃多了容易噎着。我们只是把现代软件开发的主要方向摊开在你面前，告诉你每条路通向哪、路上要打哪些小怪、打到什么程度算过关。

## 这是一张地图，不是教科书

网上教程多如牛毛，大多数人学着学着就迷路，原因只有三个：

- **不知道学什么**：技术栈多到能铺满一张床，不知道从哪下脚。
- **不知道怎么学**：知识点像散装零件，单个都认识，拼不成一台机器。
- **不知道学到什么程度**：基础、进阶、实战，每个阶段该掌握什么，心里没数。

学习路线就是来解决这三件事的。它是**地图**：告诉你从 A 到 B 怎么走、路上会遇见什么、哪里有坑。但风景得你自己看，代码得你自己敲——地图不会替你走路，只会让你少走弯路。

## 地图怎么看

每一张路线页都是一条"主线任务链"，按章节推进。建议的玩法只有四步：

1. **选一条主线**：先根据兴趣选一个方向（下面有推荐），不要同时开三条线，你不是触手怪。
2. **一章一章过**：每章讲清楚"要学什么、为什么学、学到什么程度"，别跳关，也别在某一关死磕太久。
3. **边学边动手**：看到的知识点当天就要在编辑器里见一面。看十遍不如敲一遍，敲十遍不如敲坏一遍——报错才是最好的老师。
4. **过了检查点再前进**：每章末尾通常有"通关标准"，能独立做到再进下一章。学得慢不丢人，学得假才丢人。

## 零基础：建议从这条主线开局

如果你是第一次接触编程，别纠结，按下面这条线走，每一步都给你备好了路线页：

1. **先见见网页长什么样**：HTML 和 CSS——它们不算是编程语言，更像是"搭积木 + 化妆"，成就感来得最快。[HTML & CSS 学习路线](/learning-paths/frontend/html-css)
2. **让页面活过来**：JavaScript，前端的灵魂，也是本文档里坑和梗最多的一门语言，值得认真对待。[JavaScript 学习路线](/learning-paths/languages/javascript)
3. **挑一个框架当主武器**：React 或 Vue 二选一，别贪。学完一个，另一个上手会快得让你惊讶。[React 学习路线](/learning-paths/frontend/react) ｜ [Vue 学习路线](/learning-paths/frontend/vue)
4. **学会存档和读档**：Git 版本控制 + 终端基本操作，这是每个开发者的肌肉记忆，越早练越好。[Git 学习路线](/learning-paths/tools/git) ｜ [终端学习路线](/learning-paths/tools/terminal)
5. **摸到后端的大门**：选一门语言往后端走——想少学一门语言就选 Node.js（还是 JavaScript），想看看另一片天空可以试试 Python。[Node.js 学习路线](/learning-paths/backend/nodejs) ｜ [Python 学习路线](/learning-paths/languages/python)
6. **让数据住进数据库**：先会 MySQL 的增删改查，你就理解了互联网公司大半的数据流转。[MySQL 学习路线](/learning-paths/database/mysql)
7. **把作品放上互联网**：Linux + Docker，学会"部署"这个魔法，你的代码才真正开始值钱。[Linux 学习路线](/learning-paths/devops/linux) ｜ [Docker 学习路线](/learning-paths/devops/docker)

走完这条线，你已经有能力独立做出并上线一个完整的网站。之后是继续深造前端、转后端、还是扑向 AI，就看你的兴趣了。

### 通用基础：人人要修的公共课

不管走哪条主线，这些技能早晚用得上，建议在主线卡关时穿插学习，当"支线任务"刷。

- **计算机科学与数学**：算法、系统、网络、理论、离散数学、线性代数、概率与统计提供跨领域的共同语言。[计算机科学基础](/learning-paths/cs-basics/overview) ｜ [数学基础](/learning-paths/mathematics/overview)
- **编程语言**：JavaScript、TypeScript、Go 和 Rust 现在拥有独立的语言入口；后端框架页只讨论服务端实践，不再重复导航。[编程语言总览](/learning-paths/languages/overview)
- **工具、构建与依赖**：Git、编辑器、调试、AI 编程工具、包管理和构建系统组成日常工作流。[工具与工作流](/learning-paths/tools/overview) ｜ [构建与依赖](/learning-paths/build-tools/overview)

- **数据库与中间件**：从数据模型、事务、索引到消息、搜索与对象存储。[数据库与存储](/learning-paths/database/overview) ｜ [中间件与集成](/learning-paths/middleware/overview)

## 学到什么程度算过关

不同路线有各自的通关标准，但通用的"毕业线"只有四条，可以随时拿来自检：

1. **讲得清**：能不用术语堆砌，把学过的概念给小白讲明白。
2. **写得出**：合上教程，能独立从零写出对应功能的代码。
3. **排得掉**：遇到报错不慌，能自己定位问题、读懂错误信息。
4. **交得货**：能拿学的东西做出一个完整的小作品，哪怕很丑。

满足这四条，这段路就算走扎实了。别跟别人比进度——有人三个月能肝完的路，有人要一年，都很正常。学习是马拉松，不是百米冲刺。慢慢来，比较快。

## 路线页里提到的知识点去哪了

路线页只负责"指路"：告诉你要学什么、按什么顺序、坑在哪里。至于每个知识点的详细展开、代码示例和踩坑实录，会陆续沉淀在技能书（学习笔记）板块里——将来你在路线正文里看到某个知识点，直接点它就能跳到对应的笔记页面。目前笔记还在赶工中，等它补全后，路线与笔记会正式接通。

现在，从侧边栏挑一条主线，出发吧。迷路了就回来看看地图——它一直在这儿。
