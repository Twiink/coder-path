# 升级路线图

欢迎来到程序员的成长地图。这里不会告诉你"21天精通XXX"的神话，也不会画大饼说"学完这个年薪百万"。我们只是把现代软件开发的各个方向整理出来，告诉你每条路怎么走，学什么，怎么学。

## 为什么需要学习路线？

互联网上的教程多如牛毛，但很多人学着学着就迷路了：

- **不知道学什么**：技术栈太多，不知道从哪里开始
- **不知道怎么学**：零散的知识点拼不成完整的体系
- **不知道学到什么程度**：基础、进阶、实战，每个阶段该掌握什么

学习路线就是解决这些问题的。它不是教程，而是**地图**——告诉你从A到B怎么走，路上会遇到什么，但具体的风景还得你自己去看。

## 这里有什么？

我们梳理了软件开发的主要方向：

**前端开发** - 从 HTML/CSS/JavaScript 基础到 Vue/React 框架，再到 Next.js/Nuxt.js 全栈开发，构建现代化的用户界面

**后端开发** - Node.js、Java、Python、Go 等多语言后端开发，涵盖主流框架和技术栈

**AI 开发** - 从 AI Agent 基础到 LangChain/LlamaIndex，再到 RAG 系统和向量数据库，构建智能应用

**移动开发** - Android/iOS 原生开发，以及 React Native/Flutter/uni-app 等跨平台方案

**桌面开发** - Electron、Tauri、Flutter Desktop，让你的应用跑在桌面上

**数据库** - MySQL、PostgreSQL、MongoDB、Redis，数据存储与管理的核心技能

**DevOps** - Linux、Docker、Kubernetes、CI/CD，从开发到部署的完整流程

**开发工具** - Git、VS Code、终端、Claude Code，提升开发效率的利器

每个方向下面都有具体的技术路线，告诉你该学什么、怎么学、学到什么程度。

## 如何使用这些学习路线？

1. **选择方向** - 根据兴趣或职业规划，选择一个主攻方向
2. **跟着路线走** - 每条路线都会告诉你学习的顺序和重点
3. **动手实践** - 看再多不如写一行代码，每学一个知识点都要动手试试
4. **不要贪多** - 先把一个方向学扎实，再考虑拓展其他方向

记住：学习是个马拉松，不是百米冲刺。慢慢来，比较快。
