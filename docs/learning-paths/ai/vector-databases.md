# 向量数据库

向量数据库存的不是文字，是"语义"。能搜"意思相近"的内容，而不只是关键词。这是 RAG、推荐系统、语义搜索的核心技术。

## 基础篇

> 📖 篇笔记：[向量数据库选型与实战](/study-notes/ai/vector-database-selection-practice)

先理解向量数据库的本质：

- **什么是向量（Embedding）**：文本的"语义指纹"
- **为什么需要向量数据库**：传统数据库不懂"意思"
- **相似度计算**：余弦相似度、欧氏距离、点积
- **向量数据库 vs 传统数据库**：结构和查询方式的区别
- **基本操作**：插入、搜索、更新、删除
- **Chroma 快速上手**：最简单的本地向量库

## 进阶篇

不同场景选不同的数据库：

- **FAISS 详解**：Facebook 的高性能向量库
- **索引类型对比**：Flat、IVF、HNSW、PQ 各有什么特点
- **Pinecone 云端方案**：全托管、自动扩展
- **Weaviate 功能**：混合搜索、GraphQL、自动分类
- **Qdrant 特性**：Rust 编写、高性能、易部署
- **Milvus 架构**：分布式、云原生、大规模场景
- **选型指南**：根据数据规模、预算、部署方式选择

## 实战篇

真实项目中的应用：

- **构建语义搜索引擎**：从文档到可搜索的系统
- **Metadata 过滤**：category、date、author 等条件筛选
- **批量操作优化**：提高插入和查询性能
- **持久化策略**：保存和加载索引
- **增量更新**：不重建索引的情况下添加数据
- **性能优化技巧**：批量操作、索引选择、缓存策略
- **监控与调试**：查询延迟、内存使用、慢查询分析

## 高级主题

深入理解向量数据库：

- **降维技术**：PCA 减少维度，提升性能
- **量化压缩**：减少存储空间，略微牺牲精度
- **混合索引**：向量 + 标量混合查询
- **分布式部署**：水平扩展、负载均衡
- **备份与恢复**：数据安全策略
- **成本优化**：存储、计算、网络的平衡
