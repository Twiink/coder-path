# AI Agent 基础

想让 AI 不只是回答问题，还能自己动手干活？这就是 Agent 的领域。从最简单的对话机器人，到能自主规划任务的智能体，这条路线会带你从入门到精通。

## 基础篇

掌握这些，你就能构建第一个能用的 Agent：

- **Agent 核心概念**：感知、决策、行动、记忆四大要素
- **最简单的 Agent 实现**：一个能记住对话的聊天机器人
- **System Prompt 设计**：给 Agent 定义"人格"和行为准则
- **对话上下文管理**：如何在有限 token 下保留关键信息

- **Token 计算与预算控制**：别让长对话把钱烧光
- **记忆策略选择**：完整记忆 vs 窗口记忆 vs 总结记忆

## 进阶篇

能调用工具的 Agent 才是真正有用的 Agent：

- **ReAct 模式**：Reasoning + Acting 的经典范式
- **工具定义与注册**：让 Agent 知道有哪些工具可用
- **Function Calling**：OpenAI 的标准工具调用方式
- **工具执行与错误处理**：工具调用失败了怎么办
- **多工具协同**：搜索 + 计算 + 数据库查询的配合
- **Planning 能力**：让 Agent 先想后做，不是一顿乱锤
- **自我反思机制**：从执行结果中学习改进

## 实战篇

动手做个真实项目，学得最快：

- **客服机器人**：处理常见问题，需要时转人工
- **代码助手**：能搜索文档、生成代码、执行测试
- **数据分析 Agent**：查询数据库、生成报表、可视化
- **自动化测试 Agent**：执行测试用例、记录问题、生成报告
- **Agent 性能监控**：响应时间、token 使用、成功率追踪
- **安全防护**：防止提示词注入、限制工具权限、审计日志

## 下一步学习

Agent 只是开始，深入下去还有：

- **Prompt Engineering** → 写出让 Agent 更聪明的提示词
- **LangChain 框架** → 用现成工具快速搭建 Agent
- **自主 Agent** → AutoGPT/AutoGen，让 Agent 自己规划整个任务流程
- **RAG 系统** → 给 Agent 接入你的知识库，让它回答领域问题
