# Claude API 使用

Claude 是 Anthropic 的 AI 模型，以安全、准确、长文本理解著称。200K 上下文窗口是它的杀手锏，整本书都能塞进去。

## 基础篇

先把基础 API 用起来：

- **模型系列选择**：Haiku 快、Sonnet 平衡、Opus 强，怎么选
- **基础调用**：Messages API 的使用
- **System Prompt 设计**：定义 Claude 的角色和行为准则
- **多轮对话管理**：自己维护上下文历史
- **Temperature 和 Top-p**：控制输出的随机性
- **Token 计算**：估算成本，避免超预算

## 进阶篇

发挥 Claude 的特色能力：

- **流式输出**：实时显示生成内容，用户体验更好
- **Vision 能力**：分析图片、截图、UI 设计
- **长文本处理**：200K 上下文的威力，整本书都能读
- **结构化输出**：让 Claude 输出 JSON、XML 等格式
- **Prompt Caching**：缓存长 prompt，节省 90% 成本
- **Function Calling 替代**：Claude 的工具使用方式
- **批量处理**：异步处理多个请求

## 实战篇

真实场景下的应用：

- **文档问答系统**：基于超长文档回答问题
- **代码审查助手**：分析代码质量、提建议
- **UI 分析工具**：上传截图，Claude 给出改进建议
- **多轮对话机器人**：保持上下文的智能助手
- **成本控制系统**：监控 token 使用，设置预算告警
- **错误处理与重试**：网络波动、限流的应对策略
- **性能优化**：缓存、并发、流式输出的组合

## 最佳实践

用好 Claude 的技巧：

- **选对模型**：根据任务复杂度选择
- **充分利用长上下文**：一次性处理整个文档
- **善用 Prompt Caching**：重复的 prompt 只算一次钱
- **结构化输出**：指定格式，减少解析错误
- **批处理优化**：异步并发提高吞吐量
- **监控成本**：实时追踪花费，避免爆预算
