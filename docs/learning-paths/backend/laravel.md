# Laravel 学习路线

PHP 界的艺术品，Laravel 把优雅的语法、强大的功能、完善的生态结合得恰到好处。如果你觉得 PHP 过时了，Laravel 会改变你的看法。

## 为什么选择 Laravel

WordPress 用的是老派 PHP，Laravel 用的是现代 PHP。它有优雅的 ORM（Eloquent）、强大的模板引擎（Blade）、完善的认证系统、队列处理、任务调度，还有活跃的社区和丰富的扩展包。

适合快速开发 Web 应用、内容管理系统、电商平台。Laravel 的哲学是"让开发者快乐"，用过就知道。
