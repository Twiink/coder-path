# Rust Web 学习路线

Rust 以内存安全和极致性能著称，用它写 Web 服务就像开着跑车送外卖，性能爆表、零成本抽象、线程安全。如果你追求极致性能和安全，Rust Web 是终极选择。

## 为什么选择 Rust Web

Go 快，Rust 更快。C++ 快，但不安全。Rust 给你 C++ 的性能和内存安全的保证，编译器会阻止你写出内存泄漏和数据竞争的代码。虽然学习曲线陡峭，但一旦掌握，你会发现写 Rust 代码是种享受。

适合高性能 API 服务、系统级编程、嵌入式系统。Discord、Cloudflare、Figma 的关键组件都在用 Rust 重写。

## 学习路线图

### 基础篇：Rust 语言与 Web 框架

- **Rust 语言基础**
  - 所有权系统（Ownership）
  - 借用和引用（Borrowing & References）
  - 生命周期（Lifetimes）
  - 结构体和枚举
  - 模式匹配
  - 错误处理（Result、Option）

- **异步编程**
  - async/await 语法
  - Future 和 Task
  - Tokio 运行时
  - 异步 I/O 操作
  - 并发控制

- **框架选择**
  - Actix-web：性能极致，Actor 模型
  - Axum：现代化设计，Tokio 出品
  - Rocket：优雅语法，宏驱动
  - 框架对比和选型

- **Axum 快速开始**
  - 项目初始化和依赖
  - 路由定义和处理器
  - 提取器（Extractors）
  - 响应类型
  - 状态共享

- **路由与处理**
  - 路径参数提取
  - 查询参数提取
  - JSON 请求体
  - 表单数据
  - 路由嵌套和组合

---

Rust 的学习曲线很陡，但一旦掌握，你会获得无与伦比的性能和安全保证。编译器会在编译时捕获大部分错误，运行时几乎不会出现内存问题。适合对性能和安全有极高要求的场景。
