# Flask 学习路线

Python 界的极简主义者，微框架的代表作，Flask 给你自由，让你自己决定怎么搭建应用。没有强制的目录结构，没有复杂的配置，只有你和代码的对话。

## 为什么选择 Flask

Django 是个全能管家，什么都替你准备好了。Flask 是个工具箱，你需要什么自己拿。这种自由既是优点也是挑战：小项目飞快，大项目需要自己做架构设计。

Flask 适合 API 服务、原型开发、小型 Web 应用，或者任何你想要完全控制的场景。它的核心代码只有几千行，阅读源码也不费劲，是学习 Web 框架原理的好教材。

## 学习路线图

### 基础篇：核心概念

- **快速开始**
  - 安装和环境配置
  - 创建第一个 Flask 应用
  - 开发服务器和调试模式
  - 应用配置

- **路由系统**
  - 路由定义和装饰器
  - 动态路由和参数
  - URL 转换器（int、float、path、uuid）
  - HTTP 方法处理（GET、POST、PUT、DELETE）
  - URL 构建和反向解析

- **请求与响应**
  - request 对象（查询参数、表单数据、JSON）
  - 文件上传处理
  - Headers 和 Cookies
  - 响应对象和状态码
  - 重定向和错误页面
  - 流式响应

- **模板渲染**
  - Jinja2 模板引擎
  - 模板语法（变量、标签、过滤器）
  - 模板继承和包含

  - 上下文处理器
  - 自定义过滤器和宏

---

Flask 的哲学是"做一件事并做好"，它提供核心功能，其余的你自己选择。这种设计让 Flask 既简单又灵活，适合快速原型和小型应用。大型项目需要你自己做好架构设计，但这也是学习的好机会。
