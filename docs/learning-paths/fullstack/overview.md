# 全栈开发学习路线

前端、后端、数据库、部署，一个人搞定全链路。全栈工程师不是"什么都会一点"的万金油，而是能独立完成产品从 0 到 1 的实战派。

## 全栈工程师的能力地图

**前端能力**
- HTML/CSS/JavaScript 基础扎实
- 至少精通一个前端框架（React/Vue/Angular）
- 响应式设计与移动端适配
- 性能优化与用户体验

**后端能力**
- 至少一门后端语言（Node.js/Python/Java/Go）
- RESTful API 设计
- 数据库设计与 SQL
- 认证授权（JWT/OAuth）
- 缓存与消息队列

**DevOps 能力**
- Git 版本控制
- Docker 容器化
- CI/CD 自动化部署
- 云服务（AWS/Azure/阿里云）
- 监控与日志

**软技能**
- 产品思维（理解业务需求）
- 架构设计（系统如何拆分）
- 沟通协作（跨团队合作）
- 快速学习（技术栈日新月异）

## 选择你的主力语言

全栈工程师不是"什么都会一点"，而是**有一条主线**：前端、后端、数据库、部署，能用同一套语言生态贯穿起来。先选主力语言，再顺着该体系补齐：

- **JavaScript 全栈** - 一门语言通吃前后端，React/Vue + Node.js，生态最大、上手最快 → 见 [JavaScript 全栈](/learning-paths/fullstack/javascript)
- **Python 全栈** - Django/FastAPI 开发效率极高，自带 ORM 与 Admin，适合快速迭代与 AI 应用 → 见 [Python 全栈](/learning-paths/fullstack/python)
- **Java 全栈** - Spring Boot 企业级生态成熟稳定，大型项目与团队协作的首选 → 见 [Java 全栈](/learning-paths/fullstack/java)
- **Go 全栈** - 高并发、单二进制部署，云原生时代的效率之选 → 见 [Go 全栈](/learning-paths/fullstack/go)

## 全栈通用工程实践

选定语言后，每个全栈开发者都会遇到同样的工程问题，这些是必刷的公共副本：

- [前后端协作](/learning-paths/fullstack/collaboration) - API 设计、错误处理、类型共享
- [性能优化](/learning-paths/fullstack/performance) - 前端代码分割与缓存、后端查询与缓存
- [测试](/learning-paths/fullstack/testing) - 前端单元测试、后端接口测试、E2E
- [部署与监控](/learning-paths/fullstack/deployment) - Vercel/Docker/数据库迁移/CI/CD，日志与错误监控

## 下一步学习

- **微服务架构** - 系统拆分与服务间通信
- **GraphQL** - 替代 REST 的 API 查询语言
- **Next.js / Nuxt** - 全栈框架
- **云原生** - Kubernetes、Serverless
- **Web3** - 区块链与去中心化应用

---

全栈开发是一条宽广的道路，不可能精通所有技术。选择一个主技术栈深入学习，其他技术了解概念和能快速上手即可。重要的是理解前后端如何协作、系统如何设计、问题如何解决。保持好奇心，持续学习，你会越走越远。加油，全栈工程师！
