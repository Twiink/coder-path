# Java 全栈学习路线

Java 全栈以 Spring Boot 为核心，企业级生态成熟、稳定性强，是大型项目与金融行业的标配。学习曲线更陡，但后端深度与职业天花板都相当可观。

## Spring Boot + Vue

**后端：Spring Boot**
- 企业级框架
- 成熟的生态
- 适合大型项目

**前端：Vue 3**
- 渐进式框架
- 组合式 API
- Vite 构建


## Spring Boot + React

Spring Boot 并不绑定前端框架——配 React 同样常见：

- 同一套 REST API，前端在 Vue/React 之间自由切换
- Spring Security + JWT 做认证授权
- MyBatis-Plus / Spring Data JPA 操作数据库
- Swagger / knife4j 自动生成接口文档
