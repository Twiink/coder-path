# 性能优化

性能是"抠"出来的：前端管好加载与渲染，后端管好查询与缓存，两端一起使劲。
## 前端优化

**代码分割**
用 React.lazy + Suspense 按需加载页面组件，首屏只下载当前路由的代码。

**图片优化**
用 next/image（自动压缩、响应式 srcset）或原生 loading="lazy" + srcset/sizes，按屏幕宽度加载合适尺寸。

**缓存策略**
用 TanStack Query 管理服务端状态，配置 staleTime（如 5 分钟内不重复请求）与 cacheTime（如 10 分钟后清理缓存）。

## 后端优化

**数据库查询优化**
预加载关联避免 N+1；常用查询字段（authorId、createdAt）建索引；列表接口用 skip/take 分页，而不是一次全查。

**缓存**
先查 Redis → 未命中再查库并回填 → 设置过期时间（如 3600 秒）；让接口先问缓存、再问数据库。
