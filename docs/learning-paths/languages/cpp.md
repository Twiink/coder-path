# C++ 学习路线

C++，这门"既想贴近硬件又想抽象优雅"的语言，以其强大的性能和灵活性，统治着系统编程、游戏开发和高性能计算领域。它既是 C 的超集，又有着自己的现代化特性。学 C++ 就像学武功，内功深厚才能驾驭各种招式。

## 基础篇

### C++ 入门
- **环境搭建**：编译器选择（GCC、Clang、MSVC）、IDE 配置（Visual Studio、CLion、VS Code）
- **基本语法**：变量、数据类型、常量、运算符
- **控制流**：if/else、switch、for/while/do-while 循环
- **函数**：函数定义、参数传递、返回值、函数重载
- **命名空间**：namespace、using 声明、作用域解析运算符

```cpp
#include <iostream>
int main() {
    std::cout << "Hello, C++!" << std::endl;
    return 0;
}
```

**下一步学习**：基础语法是地基，指针和引用是 C++ 的灵魂。

### 指针与引用
- **指针基础**：指针定义、取地址运算符、解引用、指针运算
- **数组与指针**：数组名即指针、指针遍历数组
- **指针的指针**：多级指针、指针数组、数组指针
- **引用**：引用定义、引用 vs 指针、const 引用
- **函数参数传递**：值传递、指针传递、引用传递
- **返回值**：返回引用、返回指针、悬空引用问题

**下一步学习**：指针是内存操作的钥匙，动态内存管理是必修课。

### 动态内存管理
- **new/delete 操作符**：动态分配单个对象、动态分配数组
- **内存泄漏**：忘记释放内存的后果
- **悬空指针**：访问已释放内存的危险
- **二维动态数组**：指针数组实现
- **内存管理原则**：谁分配谁释放、RAII 思想预告

**下一步学习**：手动管理内存容易出错，对象和类让代码更安全。

### 类与对象基础
- **类的定义**：class 关键字、成员变量、成员函数
- **访问控制**：public、private、protected
- **构造函数**：默认构造、带参构造、初始化列表、委托构造
- **析构函数**：资源清理、调用时机
- **this 指针**：隐式参数、返回 *this
- **静态成员**：static 成员变量、static 成员函数
- **友元**：friend 函数、friend 类

**下一步学习**：类是封装的基础，继承和多态让 OOP 完整。

### 继承与多态
- **继承**：public/protected/private 继承、基类与派生类
- **构造与析构顺序**：基类先构造后析构
- **虚函数**：virtual 关键字、动态绑定、虚函数表（vtable）
- **纯虚函数**：抽象基类、接口设计
- **虚析构函数**：防止内存泄漏的关键
- **多继承**：菱形继承问题、虚继承
- **override/final 关键字**：C++11 增强多态安全性

**下一步学习**：继承是 is-a 关系，运算符重载让自定义类型更自然。

### 运算符重载
- **可重载运算符**：算术、比较、赋值、下标、函数调用
- **成员函数 vs 友元函数**：this 指针的影响
- **赋值运算符**：深拷贝、返回 *this
- **拷贝构造函数**：对象复制、深拷贝 vs 浅拷贝
- **移动语义预告**：C++11 的性能优化

**下一步学习**：运算符重载让类像内置类型，STL 是 C++ 的武器库。

## 进阶篇

### STL 标准模板库
- **容器**：
  - 序列容器：vector、deque、list、forward_list、array
  - 关联容器：set、map、multiset、multimap
  - 无序容器：unordered_set、unordered_map
  - 容器适配器：stack、queue、priority_queue
- **迭代器**：五种类型、begin/end、反向迭代器
- **算法**：sort、find、binary_search、copy、transform、accumulate
- **函数对象**：仿函数、lambda 表达式（C++11）
- **适配器**：绑定器、取反器

**下一步学习**：STL 提供容器，模板让你自己造轮子。

### 模板编程
- **函数模板**：template 关键字、类型推导、显式实例化
- **类模板**：泛型类、模板参数、模板特化
- **模板特化**：全特化、偏特化
- **非类型模板参数**：整数、指针、引用
- **模板元编程**：编译期计算、类型萃取
- **变参模板**：C++11、参数包、递归展开
- **SFINAE**：替换失败不是错误

**下一步学习**：模板是编译期魔法，智能指针是现代 C++ 的标志。

### 智能指针与 RAII
- **RAII 原理**：资源获取即初始化、析构函数自动清理
- **unique_ptr**：独占所有权、移动语义、自定义删除器
- **shared_ptr**：共享所有权、引用计数、循环引用问题
- **weak_ptr**：打破循环引用、观察者模式
- **make_unique/make_shared**：推荐的创建方式
- **智能指针使用原则**：所有权语义、性能考虑

**下一步学习**：智能指针管理资源，移动语义提升性能。

### C++11/14/17 现代特性
- **移动语义**：右值引用、std::move、移动构造、移动赋值
- **完美转发**：std::forward、万能引用
- **auto 关键字**：类型推导、decltype
- **范围 for 循环**：遍历容器更简洁
- **lambda 表达式**：捕获列表、匿名函数
- **constexpr**：编译期常量、constexpr 函数
- **nullptr**：替代 NULL 和 0
- **强类型枚举**：enum class
- **结构化绑定**：C++17、解包元组和结构体
- **std::optional**：可选值类型
- **std::variant**：类型安全的 union
- **std::any**：类型擦除

**下一步学习**：现代特性让代码更安全，异常处理让程序更健壮。

### 异常处理
- **异常基础**：try-catch-throw、异常对象
- **标准异常**：std::exception 体系、logic_error、runtime_error
- **异常安全性**：基本保证、强保证、不抛出保证
- **RAII 与异常**：自动清理资源
- **noexcept 说明符**：性能优化、移动构造
- **异常 vs 错误码**：使用场景选择

**下一步学习**：异常处理保证安全，多线程让程序并发。

### 多线程编程
- **thread 库**：std::thread、join、detach
- **互斥锁**：std::mutex、lock_guard、unique_lock、scoped_lock
- **条件变量**：std::condition_variable、wait、notify
- **原子操作**：std::atomic、内存序
- **future/promise**：异步任务、async
- **线程局部存储**：thread_local
- **并发容器**：无锁数据结构
- **内存模型**：happens-before、memory_order

**下一步学习**：多线程提升性能，I/O 流处理输入输出。

## 实战篇

### 文件与 I/O 流
- **标准输入输出**：cin、cout、cerr、clog
- **文件流**：ifstream、ofstream、fstream
- **字符串流**：istringstream、ostringstream
- **格式化输出**：setw、setprecision、setfill
- **二进制文件**：read、write、seekg、seekp
- **流状态**：eof、fail、bad、good

**下一步学习**：I/O 是交互基础，网络编程连接世界。

### 网络编程基础
- **Socket 编程**：TCP/UDP、客户端/服务器模型
- **Linux Socket API**：socket、bind、listen、accept、connect
- **Windows Socket**：Winsock 库
- **多路复用**：select、poll、epoll（Linux）、IOCP（Windows）
- **第三方库**：Boost.Asio、libuv、muduo

**下一步学习**：网络编程是应用基础，高级特性让代码更强大。

### C++20/23 最新特性
- **概念（Concepts）**：类型约束、requires 子句
- **模块（Modules）**：替代头文件、import 关键字
- **协程（Coroutines）**：co_await、co_yield、co_return
- **范围库（Ranges）**：视图、管道操作符
- **三路比较**：<=> 运算符、强弱序
- **指定初始化器**：结构体初始化语法糖

**下一步学习**：新特性是趋势，性能优化是进阶。

### 性能优化
- **编译优化**：-O2/-O3 选项、内联函数
- **性能分析**：gprof、Valgrind、perf
- **内存优化**：对象池、内存对齐、缓存友好
- **算法优化**：时间复杂度、空间复杂度
- **并行计算**：OpenMP、std::execution
- **SIMD**：向量化、内联汇编

**下一步学习**：性能优化是艺术，构建系统是工程。

### 构建与工程化
- **编译流程**：预处理、编译、汇编、链接
- **Makefile**：规则、变量、自动变量
- **CMake**：现代构建工具、跨平台
- **静态库与动态库**：.a/.lib、.so/.dll
- **包管理**：Conan、vcpkg
- **代码规范**：Google C++ Style Guide、代码审查

**下一步学习**：工程化是实践，现在你已掌握 C++ 全貌！

## 学习建议

### 推荐书籍
- 《C++ Primer》：全面的入门教材
- 《Effective C++》：55 条最佳实践
- 《More Effective C++》：进阶技巧
- 《Effective Modern C++》：现代 C++ 必读
- 《C++ Concurrency in Action》：多线程权威指南
- 《深度探索 C++ 对象模型》：理解底层机制

### 学习周期
- **基础篇**：3-4 个月（每天 2-3 小时）
- **进阶篇**：4-6 个月（每天 2-3 小时）
- **实战篇**：6-12 个月（需要大量实践）

### 职业方向
- **系统编程**：操作系统、驱动开发
- **游戏开发**：游戏引擎、图形渲染
- **高性能计算**：科学计算、金融交易系统
- **嵌入式开发**：物联网、硬件控制
- **音视频处理**：编解码、实时通信

C++ 是一门需要长期投入的语言，但掌握它后，你将拥有接近硬件的控制力和高层抽象的表达力。记住：学 C++ 就像练武，基本功扎实了，才能驾驭各种高级招式。继续坚持，你会成为 C++ 高手！
