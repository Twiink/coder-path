# C++ 学习路线

C++ 是那位一手拿着螺丝刀、一手拿着抽象设计图的工程师：它愿意把你送到硬件旁边，也愿意给你模板、泛型和高层抽象。自由很大，责任也很大；裸指针、未定义行为和生命周期问题会在你不注意时悄悄预约加班。

这份路线是 **通用基础 → 编程语言 → C++** 的独立学习地图，主线围绕现代 C++ 展开。重点不是背语法，而是理解对象生命周期、值类别、资源所有权、模板、标准库、并发、性能和 ABI。

**适合谁** ---- 想进入系统、游戏、引擎、嵌入式、音视频、金融低延迟或高性能计算，或希望真正理解“代码如何贴近机器”的开发者

**先记住一件事** ---- 现代 C++ 首先要管理资源和不变量，其次才是展示技巧；能不用裸 new/delete 的地方，别让它们重新出土

**推荐总顺序** ---- 工具链与语法 → 类型与值类别 → 指针与生命周期 → 类与 RAII → 模板与泛型 → STL 与算法 → 移动与异常 → 并发 → 性能与 ABI → 现代 C++ 工程

**本页怎么用** ---- 每站同时看语言规则、编译器行为和运行时成本；C++ 会允许很多写法，但“能编译”只是它的入场券，不是安全证明。

## 第一站：编译器、构建与语言地基

C++ 的程序要先经过预处理、编译、汇编和链接四道门。每道门都有自己的小脾气，错误信息也会用不同方式告诉你“这次不是我的错”。

**编译器与标准库** ---- 认识 GCC、Clang、MSVC、标准版本、实现扩展、标准库和 ABI 的关系

**构建与链接** ---- 掌握预处理、编译单元、汇编、链接、静态库、动态库、符号、重定位和链接错误

**CMake 与工程布局** ---- 学习目标、依赖、生成器、配置、构建目录、安装、测试和交叉编译

**基本类型与对象表示** ---- 理解整数、浮点、字符、布尔、枚举、大小、对齐、字节序和平台差异

**表达式与控制流** ---- 覆盖运算符、转换、短路、条件、循环、范围 for、结构化绑定和初始化

**声明、定义与命名空间** ---- 掌握头文件、声明定义分离、ODR、命名空间、作用域、链接属性和宏边界

**重点解释** ---- 这一站通关是能从源文件一路追到目标文件和可执行文件，并知道一个符号为什么在链接阶段失踪

## 第二站：指针、引用、值类别与生命周期

C++ 的对象都很在意“谁拥有我、我还能活多久”。指针是地址通行证，引用是别名，生命周期是合同；合同没看清，悬空引用会立刻登门。

**指针与地址** ---- 理解取址、解引用、空指针、指针运算、多级指针、函数指针和数组退化

**引用与 const** ---- 掌握左值引用、右值引用、const 引用、引用折叠和参数传递取舍

**左值、右值与值类别** ---- 学习 lvalue、xvalue、prvalue、临时对象、移动机会和表达式分类

**对象生命周期** ---- 理解存储期、作用域、构造、析构、临时量、延长生命周期和初始化顺序

**动态内存** ---- 认识 new/delete、数组分配、分配器、内存泄漏、双重释放、越界和未定义行为

**数组、字符串与视图** ---- 区分原生数组、std::array、std::vector、字符串、string_view、span 和所有权

**重点解释** ---- 这一站要能回答对象由谁创建、由谁销毁、谁可以修改、引用何时失效，并能识别一段代码的生命周期风险

## 第三站：类、继承与 RAII

C++ 的类像一所既有门卫又有维修队的房子：构造时建立不变量，析构时清理资源，RAII 负责让资源跟着对象一起进退。

**类与特殊成员函数** ---- 掌握构造器、析构器、拷贝构造、拷贝赋值、移动构造、移动赋值和默认生成规则

**初始化与成员顺序** ---- 理解初始化列表、字段声明顺序、基类先行、成员对象和异常安全

**封装与不变量** ---- 设计私有状态、访问接口、const 成员函数、可变成员、友元和类不变量

**继承与虚函数** ---- 学习单/多继承、虚函数、override、final、虚析构、切片和动态绑定

**多继承与虚继承** ---- 了解菱形继承、虚基类、布局、指针调整和复杂度边界

**运算符与用户定义类型** ---- 掌握运算符重载、转换函数、三路比较、字面量和隐式转换控制

**RAII 与异常安全** ---- 理解资源获取即初始化、作用域清理、基本/强/不抛异常保证和事务式更新

**重点解释** ---- 这一站通关是能让对象自己负责资源，让异常路径也安全收尾，并能说明什么时候组合比继承更适合

## 第四站：模板、概念与泛型编程

模板是 C++ 的另一位大脑：它在编译期替你生成代码，能力很强，错误信息也可能长得像一封来自古代的信。现代 C++ 正在用 concepts 给它装路标。

**函数与类模板** ---- 掌握模板参数、实例化、推导、默认参数、非类型参数和模板特化

**模板元编程** ---- 认识编译期计算、类型萃取、SFINAE、偏特化、折叠表达式和 constexpr

**concepts 与 requires** ---- 理解约束、可读性、重载选择、错误诊断和能力导向的泛型接口

**完美转发** ---- 学习 forwarding reference、std::forward、引用折叠、参数保留和转发陷阱

**类型推导** ---- 掌握 auto、decltype、decltype(auto)、模板推导和初始化差异

**编译期与运行期边界** ---- 区分 constexpr、consteval、constinit、编译期分支、反射缺口和代码膨胀

**重点解释** ---- 这一站要能写出约束清楚的泛型接口，知道模板为何实例化、何时膨胀、何时该用普通多态或组合

## 第五站：STL、迭代器与算法

标准库像一座装备齐全的仓库：容器负责存货，迭代器负责带路，算法负责干活，范围库则试图把它们安排得更像一句完整的话。

**序列容器** ---- 比较 vector、deque、list、forward_list、array 的布局、迭代器失效和复杂度

**关联容器** ---- 掌握 map、set、multimap、multiset、unordered 家族、比较器、哈希和节点句柄

**适配器与资源容器** ---- 认识 stack、queue、priority_queue、optional、variant、any、pair 和 tuple

**迭代器模型** ---- 理解输入、输出、前向、双向、随机访问、连续迭代器和失效规则

**算法与范围** ---- 学习排序、搜索、复制、变换、归并、堆、数值算法、ranges、views 和惰性组合

**分配器与内存资源** ---- 了解 allocator、pmr、单调资源、对象池、局部性和定制分配的代价

**重点解释** ---- 这一站通关是能按布局、所有权、访问方式和失效规则选择 STL 组件，而不是看到容器名就随机抽签

## 第六站：移动语义、智能指针与现代资源管理

C++ 很早就发现“复制一份东西”可能很贵，于是请来了移动语义。对象不必搬家，可以把钥匙交出去；但钥匙交完以后，原对象仍要保持合法状态。

**拷贝与移动** ---- 理解深拷贝、浅拷贝、移动构造、移动赋值、noexcept 和被移动对象状态

**规则与零规则** ---- 掌握三/五/零法则、特殊成员函数默认生成和资源类设计

**unique_ptr** ---- 学习独占所有权、删除器、数组、转移和多态析构

**shared_ptr 与 weak_ptr** ---- 理解控制块、引用计数、循环引用、别名构造、线程安全和所有权边界

**所有权视图** ---- 区分裸指针、引用、observer pointer、span、string_view 和拥有/借用关系

**异常安全与事务** ---- 设计提交/回滚、强保证、资源守卫和跨接口所有权转移

**重点解释** ---- 这一站要能把所有权说清楚，让智能指针服务设计而不是替设计打补丁

## 第七站：并发、内存模型与协程

并发会把 C++ 的每个细节都放大：一个数据竞争能把正确程序变成概率艺术，一个锁顺序能让所有线程在门口排队。编译器和 CPU 也会参与这场会议。

**线程与任务** ---- 掌握 std::thread、jthread、任务、线程生命周期、停止令牌和线程局部存储

**互斥与条件同步** ---- 学习 mutex、recursive_mutex、shared_mutex、condition_variable、semaphore、latch 和 barrier

**原子与内存序** ---- 理解 atomic、CAS、relaxed、acquire/release、seq_cst、fence 和无锁结构

**数据竞争与死锁** ---- 识别竞争、死锁、活锁、饥饿、优先级反转和锁粒度

**并发队列与执行器** ---- 了解生产者消费者、任务池、工作窃取、背压、取消和执行器设计

**协程** ---- 认识 coroutine、promise、awaiter、挂起点、生成器、异步任务和生命周期陷阱

**重点解释** ---- 这一站通关是能说明共享状态、内存可见性、同步、取消和协程生命周期，知道“无锁”不等于“无风险”

## 第八站：未定义行为、性能与 ABI

C++ 有些地方不会直接说“不行”，而是把解释权交给实现，顺便把程序送进未知领域。这一站负责给这些边界装护栏，也负责把性能从感觉拉回测量。

**未定义、未指定与实现定义** ---- 区分三类行为、别名规则、越界、未初始化、生命周期结束后访问和有符号溢出

**对象模型与严格别名** ---- 理解对象表示、有效类型、placement new、位拷贝、对齐和生命周期重用

**性能与局部性** ---- 关注缓存、分支、分配、虚调用、模板代码、SIMD、批处理和数据布局

**ABI 与二进制兼容** ---- 掌握布局、虚表、名称修饰、调用约定、异常 ABI、标准库 ABI 和跨编译器边界

**剖析与诊断** ---- 使用 sanitizers、调试器、性能分析、基准、火焰图、静态分析和崩溃转储

**定制内存与低延迟** ---- 了解对象池、无锁分配、实时约束、分配抖动和优化的可维护性成本

**重点解释** ---- 这一站要能先证明代码合法，再测量瓶颈，最后选择优化；不要让编译器的“没报错”替你签署安全合同

## 第九站：模块、协程与现代 C++ 工程

现代 C++ 正在努力把多年积累的能力整理成更可靠的工具。模块想告别头文件大搬家，ranges 想让算法更会表达，协程想把异步的线团重新梳顺。

**模块与头文件** ---- 认识模块接口、实现、导入、构建支持、宏边界和迁移成本

**constexpr 与编译期设计** ---- 掌握编译期验证、常量求值、静态断言和编译时间控制

**ranges 与 views** ---- 理解范围组合、惰性、视图生命周期、投影、约束和调试边界

**协程工程化** ---- 关注调度器、取消、异常、背压、生命周期和与网络库的配合

**测试与质量** ---- 建立单元、属性、模糊、集成、sanitizer、静态检查和跨平台测试

**发布与平台** ---- 掌握包管理、交叉编译、制品、符号、版本、许可证和可复现构建

**重点解释** ---- 这一站通关是能在语言新特性、编译器支持、ABI、团队能力和可维护性之间做现实选择

## 学习路径建议：从管理对象到管理系统

**第一阶段：编译与生命周期** ---- 完成前两站，能解释编译链、指针、引用、值类别和对象寿命

**第二阶段：类型与标准库** ---- 完成第三至第五站，用 RAII、模板和 STL 写出不依赖裸资源的代码

**第三阶段：移动与并发** ---- 完成第六至第七站，设计清晰的所有权、取消和同步边界

**第四阶段：性能与工程** ---- 完成第八至第九站，把 UB、ABI、剖析、测试、构建和发布纳入日常

## 通关标准

**语言通关** ---- 能解释值类别、模板推导、对象生命周期、继承、虚函数、运算符和未定义行为

**资源通关** ---- 能设计 RAII、移动、智能指针、所有权视图和异常安全

**标准库通关** ---- 能按布局、复杂度、失效和内存需求选择容器、算法、范围和分配器

**并发通关** ---- 能解释线程、原子、内存序、锁、任务、协程和取消

**工程通关** ---- 能用工具链、sanitizer、测试、剖析和 ABI 知识交付可靠程序

## 结语

C++ 不会替你把门锁好，它把钥匙交给你，然后认真观察你会不会丢。它的自由让人着迷，它的边界让人长记性；当你开始尊重生命周期、所有权、未定义行为和数据布局，C++ 才会从深渊里的野兽变成可靠的重型工具。
