# Swift 学习路线

Swift 是那位住在 Apple 生态、却把安全和性能都写进简历的工程师：值类型负责清晰，协议负责组合，ARC 负责回收，编译器负责在你把可选值当确定值时及时皱眉。

这份路线是 **通用基础 → 编程语言 → Swift** 的独立学习地图，覆盖语言类型、协议、泛型、内存、并发、工具链、互操作和 Apple/跨平台生态。

**适合谁** ---- 想学习 iOS、macOS、watchOS、服务端 Swift、SwiftUI，或希望系统理解现代静态类型与并发安全的开发者

**先记住一件事** ---- Swift 的安全不是“编译器替你做决定”，而是让所有权、可选值、错误和并发边界尽早浮出水面

**推荐总顺序** ---- 工具链与类型 → 函数与闭包 → struct/class/protocol → 泛型与关联类型 → ARC 与所有权 → 错误与 I/O → 并发 → 性能与互操作 → 平台工程

**本页怎么用** ---- 先学语言本体，再进入 SwiftUI、Apple 框架、服务端或跨平台；UI 会变化，值语义和并发模型会一直陪你工作。

## 第一站：工具链、值类型与表达式

Swift 的编译器像一位很会提前发现事故的同事：它希望你先说清数据可能是什么、谁能改、什么时候结束。

**工具链与模块** ---- 认识 Swift 编译器、SwiftPM、Xcode、模块、包、目标、构建配置和平台 SDK

**变量与常量** ---- 掌握 let/var、类型推断、作用域、初始化、属性和静态检查

**基础类型** ---- 理解整数、浮点、布尔、字符串、字符、数组、字典、集合、元组和元组标签

**表达式与控制流** ---- 覆盖 if、guard、switch、模式匹配、for、while、defer、范围和结果表达式

**可选值** ---- 学习 Optional、绑定、链式调用、空合并、强制解包和隐式可选的边界

**字符串与 Unicode** ---- 认识 Character、扩展字形、索引成本、编码、正则和字符串视图

**重点解释** ---- 这一站通关是能解释 Swift 的值、可选、初始化和 Unicode，不把强制解包当成快捷电梯

## 第二站：函数、闭包与高阶表达

Swift 的函数既可以认真上班，也可以临时兼职：能作为值、能捕获上下文、能被传递和返回。闭包很方便，也很会延长对象寿命。

**函数签名** ---- 掌握参数标签、默认参数、可变参数、inout、返回值、重载和函数类型

**闭包** ---- 理解捕获列表、逃逸/非逃逸、自动闭包、生命周期和循环引用

**高阶函数** ---- 学习 map、compactMap、flatMap、filter、reduce、sorted 和副作用边界

**函数构造** ---- 认识函数组合、泛型函数、重载解析、尾随闭包和可调用 API 设计

**属性与下标** ---- 掌握计算属性、观察器、懒属性、静态属性、下标和访问控制

**defer 与资源** ---- 理解作用域退出、逆序执行、异常/错误替代和清理责任

**重点解释** ---- 这一站要能说明闭包捕获什么、何时释放、函数类型如何传递，以及简洁语法有没有隐藏生命周期成本

## 第三站：结构体、类、协议与枚举

Swift 的类型们各有工作证：struct 擅长值语义，class 负责身份与共享，protocol 提供能力合同，enum 则认真看守状态分支。

**struct 与值语义** ---- 理解复制、写时复制、可变性、成员初始化器、嵌套类型和不变量

**class 与引用语义** ---- 掌握身份、继承、初始化链、析构、类型转换和共享状态

**协议** ---- 学习协议组合、默认实现、协议扩展、关联类型、self/associatedtype 限制和能力建模

**枚举与关联值** ---- 掌握关联值、原始值、递归枚举、模式匹配、状态机和穷尽检查

**访问控制** ---- 理解 private、fileprivate、internal、public、open、模块边界和 ABI

**泛型约定** ---- 认识协议约束、where 子句、类型擦除预告和动态/静态分派

**重点解释** ---- 这一站通关是能按值语义、身份、能力和状态选择类型，知道组合往往比继承更轻

## 第四站：泛型、协议与类型擦除

Swift 的泛型像一位很会复用工具的工匠，协议则像能力清单；但关联类型和存在类型会要求你分清“某一种具体类型”和“只知道它符合某种能力”。

**泛型函数与类型** ---- 掌握类型参数、约束、where、推断、泛型容器和泛型初始化

**协议关联类型** ---- 理解 associatedtype、Self、协议约束、递归约束和使用位置

**some 与 opaque type** ---- 学习不透明返回、静态具体类型、组合和 API 隐藏

**any 与 existential** ---- 认识存在类型、动态分派、类型擦除、性能和可用性边界

**类型擦除** ---- 了解包装器、Any、闭包擦除、迭代器和协议对象

**泛型元组与可变参数方向** ---- 关注参数包、宏/泛型演进和编译器支持

**重点解释** ---- 这一站要能解释静态泛型、协议值、类型擦除和动态分派的差别，不让类型系统变成烟雾机

## 第五站：ARC、所有权与内存安全

ARC 像一位自动收房租的管理员：引用多时对象继续住，引用归零时安排退房。但循环引用会让两位住户互相作证，谁也不肯先搬。

**ARC 模型** ---- 理解强引用、引用计数、释放时机、临时引用和优化后的生命周期

**weak 与 unowned** ---- 区分可空弱引用、无主引用、生命周期前提和崩溃风险

**闭包循环引用** ---- 掌握捕获列表、逃逸闭包、异步回调、任务和 UI 控制器生命周期

**值类型与写时复制** ---- 了解 Array/String 等集合的共享存储、修改触发复制和性能

**Unsafe 能力** ---- 认识 UnsafePointer、内存绑定、手动分配、布局、对齐和互操作边界

**所有权修饰** ---- 了解 borrowing、consuming、mutating、inout 和所有权检查方向

**重点解释** ---- 这一站通关是能画出对象引用图，识别循环、悬空和复制成本，让自动内存管理不再变成自动遗忘

## 第六站：错误、并发与异步任务

Swift 的错误和并发都喜欢把责任写在脸上：throws 要声明，async 要标记，actor 会看守状态，Sendable 则检查数据能不能跨并发边界旅行。

**错误处理** ---- 掌握 Error、throws、try、do/catch、rethrows、Result、错误映射和恢复

**async/await** ---- 理解异步函数、挂起、任务、任务组、优先级和结构化并发

**取消与超时** ---- 学习 Task cancellation、检查取消、截止时间、资源清理和部分结果

**actor 与隔离** ---- 掌握 actor、主 actor、隔离状态、跨 actor 调用和重入风险

**Sendable 与数据竞争** ---- 理解 Sendable、值类型、不可变共享、非 Sendable 对象和编译期隔离

**AsyncSequence** ---- 认识异步序列、迭代、背压、结束、错误和取消

**重点解释** ---- 这一站要能说明任务在哪里运行、状态谁保护、取消如何传播、错误如何回收，不把 async 当成装饰语

## 第七站：标准库、协议 I/O 与序列化

标准库像 Swift 的工具箱，Foundation 则像那位经验丰富的邻居：日期、URL、文件、网络和序列化都能帮忙，但边界仍需要你亲自确认。

**集合与算法** ---- 掌握 Array、Set、Dictionary、Range、Collection、Sequence、迭代器和复杂度

**日期与格式化** ---- 了解 Date、Calendar、TimeZone、Locale、Formatter、时区和夏令时

**文件与 URL** ---- 学习 URL、URLSession、FileManager、流、缓存、临时文件和权限

**Codable** ---- 掌握 Encodable/Decodable、键策略、日期、未知字段、版本兼容和错误定位

**网络与响应** ---- 理解请求、响应、缓存、重试、超时、取消、连接和后台任务

**日志与诊断** ---- 认识 os.Logger、signpost、崩溃、指标、网络日志和隐私级别

**重点解释** ---- 这一站通关是能让数据跨文件、网络、日期和序列化边界时保持可追踪、可恢复、可测试

## 第八站：性能、互操作与平台工程

Swift 可以靠近硬件，也可以和 Objective-C、C、C++、系统框架和 SwiftUI 同桌吃饭。桌子越大，ABI、线程、拷贝和平台生命周期越要提前安排。

**性能测量** ---- 使用 Instruments、signpost、Time Profiler、Allocations、Leaks、基准和真实设备

**优化方向** ---- 关注值类型复制、写时复制、泛型特化、协议分派、字符串、集合、渲染和 I/O

**Objective-C 互操作** ---- 了解桥接、动态派发、NSObject、KVO、运行时和 nullability

**C/C++ 互操作** ---- 认识 C ABI、指针、模块映射、内存所有权、错误传递和构建配置

**SwiftUI 与 UI 状态** ---- 掌握声明式视图、状态、绑定、观察、主线程、生命周期和异步数据

**SwiftPM 与发布** ---- 理解包、产品、目标、资源、插件、二进制、版本和平台条件

**重点解释** ---- 这一站要能在性能、平台 API、互操作、UI 状态和发布边界之间做有证据的选择

## 第九站：测试、工具链与生态分叉

Swift 项目也要经过质检：XCTest 会问行为，Swift Testing 会问边界，编译器会问并发，CI 会问“换一台机器还能不能过”。

**测试体系** ---- 掌握 XCTest、Swift Testing、异步测试、UI 测试、快照、Mock 和依赖替换

**并发测试** ---- 覆盖取消、竞态、时间、任务组、actor、Sendable 和确定性

**静态检查与宏** ---- 了解 SwiftLint、宏、生成代码、编译时间和错误诊断

**构建与 CI** ---- 管理 Xcode、SwiftPM、工具链版本、缓存、签名、平台矩阵和制品

**安全与隐私** ---- 关注钥匙串、证书、网络安全、隐私权限、日志脱敏和供应链

**生态方向** ---- 选择 iOS/macOS、SwiftUI、服务端 Swift、命令行、嵌入或跨平台方向

**重点解释** ---- 这一站通关是能把 Swift 项目从代码送到测试、签名、发布和观测，而不是只在模拟器里拥有完美天气

## 学习路径建议：从值语义到系统应用

**第一阶段：语言与类型** ---- 完成第一至第四站，建立可选、函数、协议、枚举、泛型和类型擦除模型

**第二阶段：内存与并发** ---- 完成第五至第六站，理解 ARC、所有权、async/await、actor 和 Sendable

**第三阶段：I/O 与平台** ---- 完成第七至第八站，处理网络、文件、序列化、性能和互操作

**第四阶段：交付与生态** ---- 完成第九站，选择 Apple、服务端或跨平台方向完成项目

## 通关标准

**语言通关** ---- 能解释 Optional、值/引用、struct/class、protocol、enum、泛型和类型擦除

**内存通关** ---- 能解释 ARC、weak/unowned、闭包捕获、写时复制和 unsafe 边界

**工程通关** ---- 能完成 SwiftPM/Xcode、测试、性能、互操作、签名和发布

## 结语

Swift 像一位把安全帽戴得很端正的工程师：它愿意让你写得漂亮，也会在你越过边界时拉住袖子。别把编译器的提醒当成阻碍，它是在帮你把问题提前搬到白天解决。等值语义、所有权和并发模型真正站稳，Swift 的优雅就不只是外观，而是系统能长期工作的秩序。
