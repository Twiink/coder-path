# Kotlin 学习路线

Kotlin 是 JVM 家族里那位穿着轻便外套的工程师：它尊重 Java 的家底，却不愿继续忍受样板代码；空安全、扩展函数、数据类、协程和 DSL 让它写起来清爽，编译器则会在关键地方认真问你“这个值真的可能为空吗？”

这份路线是 **通用基础 → 编程语言 → Kotlin** 的独立学习地图，覆盖语言语义、JVM 互操作、协程、类型系统、内存与工程生态，不是语法小抄。

**适合谁** ---- 想进入 Android、JVM 后端、跨平台、工具开发，或希望从 Java 迁移到更现代的静态类型语言的开发者

**先记住一件事** ---- Kotlin 的简洁不是少写几个字符，而是让类型、空值、状态和并发更早暴露；省下的代码要用来思考边界

**推荐总顺序** ---- 工具链与基础语法 → 类型与空安全 → 函数与集合 → 类与委托 → 泛型与 DSL → 协程 → JVM 互操作 → 内存性能 → 多平台与工程

**本页怎么用** ---- 先掌握 Kotlin 的语言模型，再分别进入 Android、服务端或 Multiplatform；不要把协程当成“更快的线程”，它们是不同角色。

## 第一站：工具链、表达式与类型

Kotlin 的编译器像一位认真但不爱唠叨的老师：它鼓励表达式、推断和不可变绑定，同时会把含糊的地方圈出来让你补证据。

**编译与运行** ---- 认识 Kotlin/JVM、Kotlin/Native、Kotlin/JS、编译器、字节码、运行时和 Gradle

**变量与表达式** ---- 掌握 val/var、类型推断、表达式返回值、控制流、范围、when 和智能转换

**基础类型** ---- 理解数字、字符、布尔、字符串、数组、装箱、平台类型和数值转换

**空安全** ---- 学习 nullable、安全调用、空合并、非空断言、let/run/also/apply 以及 Java 平台类型风险

**集合与只读视图** ---- 区分 List/Set/Map 的只读接口与可变实现，理解共享引用和真正不可变的差别

**字符串与模板** ---- 掌握 Unicode、模板、原始字符串、格式化、编码和性能边界

**重点解释** ---- 这一站通关是能解释 Kotlin 的表达式、空值、推断和平台类型，不把叹号当作空安全毕业证

## 第二站：函数、Lambda 与集合处理

Kotlin 的函数很爱串门：可以顶层居住，可以作为参数，可以带默认值，也可以变成扩展函数。集合操作则负责把一堆数据整理得像在开会。

**函数参数** ---- 掌握默认参数、命名参数、可变参数、返回类型、局部函数和尾递归限制

**高阶函数** ---- 理解函数类型、Lambda、匿名函数、闭包、调用约定和内联提示

**扩展函数与属性** ---- 学习接收者、静态解析、可空扩展、扩展属性和命名冲突

**集合操作** ---- 覆盖 map、filter、flatMap、fold、associate、groupBy、分区、排序和窗口

**Sequence 与惰性** ---- 理解 Sequence、迭代次数、中间/终止操作、短路和何时物化更划算

**作用域函数** ---- 区分 let、run、with、apply、also 的接收者、返回值和可读性边界

**重点解释** ---- 这一站通关是能从函数类型、闭包、惰性和分配成本判断一段“很 Kotlin”的代码是否真的清楚

## 第三站：类、对象、委托与状态建模

Kotlin 的类型们喜欢分工：data class 负责携带数据，sealed class 负责列出状态，object 负责守着单例，委托则表示“这活我请专业人士来做”。

**类与构造** ---- 掌握主构造器、次构造器、初始化块、属性初始化顺序和可见性

**数据类** ---- 理解 component、copy、equals/hashCode、解构和浅复制

**对象与伴生对象** ---- 认识 object、单例、companion object、工厂和初始化线程安全

**继承与接口** ---- 学习默认 final、open、override、抽象类、接口默认实现和菱形冲突

**sealed 与枚举** ---- 通过受限层次、状态机、穷尽 when 和枚举表达业务状态

**委托与属性** ---- 掌握 by、lazy、observable、可委托属性、类委托和生命周期

**运算符与约定** ---- 理解 operator、invoke、component、get/set、范围和约定方法

**重点解释** ---- 这一站要能用值对象、受限状态和组合表达领域模型，知道复制、共享和继承各自的账单

## 第四站：泛型、方差与类型系统深水区

Kotlin 的类型系统像一位会检查货物方向的仓库管理员：有些箱子只进不出，有些只出不进，星投影则表示“我知道它存在，但先别问细节”。

**泛型基础** ---- 掌握泛型类、函数、类型参数、上界、类型推断和泛型别名

**声明处方差** ---- 理解 out/in、协变、逆变、使用位置约束和 Java 通配符对应关系

**星投影与平台类型** ---- 认识星投影、未知类型、Java 原始泛型、灵活类型和边界注解

**reified 与 inline** ---- 学习具体化类型参数、内联限制、非局部返回和代码膨胀

**类型别名与高阶类型** ---- 了解 typealias、函数类型、接收者函数、挂起函数和类型组合

**反射与 KClass** ---- 认识 Kotlin 反射、Java 反射、可调用引用、性能与裁剪边界

**重点解释** ---- 这一站通关是能解释类型关系、方差、泛型擦除和 reified 的能力边界，而不是见到尖括号就开始施法

## 第五站：协程、结构化并发与流

Kotlin 协程像一群很会排班的临时工：它们能暂停、恢复和取消，但不会凭空创造 CPU；如果把阻塞任务塞进错误的线程，它们也会集体堵在门口。

**协程基本模型** ---- 理解 suspend、Continuation、CoroutineContext、Job、Scope 和调度器

**结构化并发** ---- 掌握父子任务、生命周期、异常传播、监督作用域、取消传播和资源清理

**调度器与线程** ---- 区分 Default、IO、Main、自定义调度器、线程池和阻塞边界

**任务编排** ---- 学习 launch、async、await、并发组合、超时、取消和异常聚合

**Flow** ---- 认识冷流、收集、背压、操作符、异常、取消、共享流和状态流

**Channel 与通信** ---- 理解缓冲、发送/接收、关闭、select、生产者消费者和背压

**测试与虚拟时间** ---- 了解协程测试、调度控制、确定性、取消和泄漏检测

**重点解释** ---- 这一站通关是能说明协程何时运行、在哪里运行、如何取消、如何传播异常，并知道它不是并行魔法

## 第六站：JVM 互操作与运行时

Kotlin 和 Java 住在同一栋 JVM 公寓里，平时相处融洽，偶尔会因为 null、泛型、静态成员和检查异常的生活习惯不同而互相吐槽。

**Java 互操作** ---- 掌握调用 Java 类、平台类型、可空注解、命名冲突、重载和 SAM 转换

**字节码与注解** ---- 了解生成成员、JvmStatic、JvmField、JvmName、默认参数桥接和注解目标

**泛型与擦除** ---- 理解 JVM 类型擦除、数组、检查转换、reified 和 Java API 兼容

**异常与资源** ---- 认识 Kotlin 不强制 checked exception、try 表达式、use 和 Java 资源

**类加载与反射** ---- 了解 JVM 类加载、KClass/Java Class、代理和框架扫描

**重点解释** ---- 这一站要能读懂 Java/Kotlin 混合项目中的 null、字节码、注解和泛型边界

## 第七站：内存、性能与本地能力

Kotlin 让代码变简洁，但对象不会因为语法漂亮就免费出生。集合、闭包、装箱、序列和协程都可能分配内存，性能需要测量来主持公道。

**对象与分配** ---- 理解 JVM 对象、装箱、临时对象、闭包、data class copy 和逃逸

**集合与序列性能** ---- 对比 eager collection、Sequence、数组、原生循环、分配和缓存局部性

**协程开销** ---- 关注状态机、Continuation、调度、上下文、Channel 和 Flow 的成本

**JVM 诊断** ---- 了解 GC、JFR、async-profiler、堆转储、线程栈和基准

**Kotlin/Native** ---- 认识内存管理、互操作、并发限制、二进制、编译时间和平台差异

**性能边界** ---- 理解 inline、value class、不可变性、缓存和代码可读性的取舍

**重点解释** ---- 这一站通关是能把语法便利还原成对象、分配、线程和 GC 成本，知道何时优化、何时停止炫技

## 第八站：多平台、测试与工程

Kotlin 想把同一套思维带到 Android、服务器、浏览器和原生平台，但不同平台不会完全听同一首歌；共享代码要讲边界，不能只讲愿望。

**Gradle 与项目结构** ---- 掌握模块、源集、依赖、插件、构建缓存、版本目录和发布

**Kotlin Multiplatform** ---- 了解 common、expect/actual、平台源集、共享模型和平台 API 边界

**Android 方向** ---- 认识生命周期、主线程、Compose、状态、协程、序列化和资源

**服务端方向** ---- 了解 Ktor、Spring Kotlin、HTTP、数据库、协程、观测和部署

**测试与质量** ---- 建立单元、协程、属性、集成、UI、Mock、静态检查和二进制兼容测试

**发布与兼容** ---- 关注 Kotlin 版本、编译器、标准库、二进制 API、平台矩阵和迁移

**重点解释** ---- 这一站要能根据平台、共享比例、团队和发布边界设计 Kotlin 项目，而不是为了共享而共享

## 学习路径建议：从空安全到跨平台

**第一阶段：语言与函数** ---- 完成第一至第二站，建立表达式、空值、函数、集合和闭包模型

**第二阶段：类型与建模** ---- 完成第三至第四站，掌握类、状态、委托、泛型和方差

**第三阶段：协程与 JVM** ---- 完成第五至第六站，理解异步、取消、线程、Java 互操作和字节码

**第四阶段：性能与生态** ---- 完成第七至第八站，进入 Android、服务端或多平台方向

## 通关标准

**并发通关** ---- 能解释协程、结构化并发、Flow、Channel、调度和取消

## 结语

Kotlin 像一位会把房间收拾得很漂亮的工程师：它让空值提前打招呼，让数据类少写样板，让协程负责排班。但房间漂亮不代表没有承重墙，真正的稳定仍然来自类型、生命周期、运行时和工程边界。
