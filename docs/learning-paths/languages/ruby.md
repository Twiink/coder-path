# Ruby 学习路线

Ruby 是那位相信代码也应该有生活情趣的工程师：它让对象、块、消息和元编程都显得很自然，写起来像在和程序聊天。可一旦所有人都能动态改门牌，项目也会开始怀疑自己到底住在哪里。

这份路线是 **通用基础 → 编程语言 → Ruby** 的独立学习地图，覆盖语言语义、对象模型、块与枚举器、元编程、运行时、并发、测试、安全和 Rails 生态。

**适合谁** ---- 想学习 Ruby、Rails、脚本自动化、Web 产品开发，或希望理解动态语言如何在保持表达力的同时建立工程秩序的开发者

**先记住一件事** ---- Ruby 的优雅来自对象和消息模型，但优雅需要边界管理；能写得短，不代表可以让未来的同事玩密室逃脱

**推荐总顺序** ---- 运行时与语法 → 对象模型 → 块与枚举 → 模块与元编程 → 异常与 I/O → Gems/Bundler → 并发与内存 → 测试安全 → Rails 与生产

**本页怎么用** ---- 先理解 Ruby 如何求值和查找方法，再进入 Rails；框架很会变魔术，语言本体负责告诉你魔术从哪顶帽子里出来。

## 第一站：Ruby 运行时与表达式

Ruby 的解释器像一位很有个性的导游：它愿意让表达式、消息和对象自然对话，但会在动态查找时带你绕一点路。

**实现与运行方式** ---- 认识 CRuby、JRuby、TruffleRuby、解释执行、JIT、脚本和交互式环境

**对象与字面量** ---- 理解数字、字符串、符号、数组、哈希、范围、正则、true/false/nil 和对象身份

**变量与作用域** ---- 掌握局部、实例、类、全局变量、常量、闭包和动态作用域边界

**表达式与控制流** ---- 覆盖条件、循环、case、修饰符、赋值返回值、异常和模式匹配方向

**字符串与编码** ---- 学习 Encoding、Unicode、可变字符串、冻结、插值、正则和字节边界

**方法调用** ---- 理解消息发送、隐式接收者、括号、省略 return、关键字参数和可变参数

**重点解释** ---- 这一站通关是能解释 Ruby 如何求值、寻找变量和发送消息，而不是只知道代码读起来像英语

## 第二站：对象模型、类与模块

Ruby 认为几乎一切都是对象，连类也不例外。对象们都有自己的门牌，类和模块则负责帮它们组织技能和方法。

**类与实例** ---- 掌握类对象、实例变量、类变量、单例对象、初始化和可见性

**继承与方法查找** ---- 理解 superclass、祖先链、重写、super、prepend、include 和 extend

**模块与 mixin** ---- 学习模块命名空间、能力组合、依赖、冲突和组合边界

**封装与不可变性** ---- 认识 public/protected/private、freeze、值对象和共享状态

**Struct、Data 与模式** ---- 了解结构化数据、值相等、不可变记录和现代 Ruby 数据建模

**方法与属性** ---- 掌握 attr 族、define_method、send/public_send 和动态调用风险

**重点解释** ---- 这一站要能画出一个对象的类、单例类、祖先链和方法查找顺序，知道“元编程”不是凭空发生的

## 第三站：块、迭代器与函数式表达

Ruby 的块是语言里的常驻居民：它们可以陪方法工作，可以保存状态，可以把循环写成叙事；Enumerator 则负责在数据太多时提醒大家慢慢来。

**块与 yield** ---- 理解块参数、yield、block_given、闭包捕获和块返回值

**Proc 与 Lambda** ---- 区分 Proc、lambda、return、break、参数检查和生命周期

**Enumerable** ---- 掌握 map、select、reject、reduce、group_by、partition、lazy 和链式处理

**Enumerator** ---- 学习外部迭代、内部迭代、惰性、协作和无限序列

**可调用对象** ---- 认识 method、to_proc、符号转 Proc、回调和参数转发

**并行与副作用** ---- 理解迭代中的修改、懒执行、重复遍历、异常和共享状态

**重点解释** ---- 这一站通关是能判断一段块式代码何时执行、如何返回、是否惰性，以及它到底把多少数据留在内存里

## 第四站：元编程、反射与 DSL

Ruby 的元编程像一位会自己改名片的演员：它能在运行时加方法、读常量、重写消息。能力很迷人，但每增加一层动态，调试器就少一盏灯。

**反射** ---- 掌握 respond_to、methods、ancestors、constants、instance_variables、source_location 和调用

**动态方法** ---- 学习 method_missing、respond_to_missing、define_method、class_eval、instance_eval

**单例类** ---- 理解 eigenclass、类方法、extend、prepend 和方法查找

**钩子** ---- 认识 inherited、included、extended、prepended、method_added 等生命周期回调

**DSL 设计** ---- 关注接收者、上下文、错误信息、静态可读性和配置边界

**元编程风险** ---- 防范隐式依赖、命名冲突、动态代码执行、性能和安全问题

**重点解释** ---- 这一站要能读懂 Rails 等框架的 DSL，并能判断显式代码是不是比动态魔法更适合维护

## 第五站：异常、资源、文件与网络

Ruby 的异常会沿着调用栈旅行，IO 对象则会期待你在离场前关灯。资源管理不是礼貌问题，是稳定性问题。

**异常体系** ---- 掌握 Exception 层级、raise、rescue、else、ensure、重新抛出和自定义异常

**错误边界** ---- 区分程序错误、输入错误、业务冲突、外部故障和可恢复异常

**文件与 IO** ---- 学习 File、IO、缓冲、编码、目录、临时文件、管道和资源清理

**序列化与配置** ---- 认识 JSON、YAML 风险、Marshal、ENV、配置分层和版本兼容

**进程与信号** ---- 了解 system、spawn、Open3、退出码、信号、子进程和优雅关闭

**网络与超时** ---- 掌握 Socket、HTTP、TLS、连接、超时、重试和资源池边界

**重点解释** ---- 这一站通关是能让 IO、进程、网络和异常在成功、失败和取消时都能清理并留下证据

## 第六站：Gems、Bundler 与项目工程

Gems 是 Ruby 的邻居们，Bundler 是物业管理员：它负责版本、依赖和环境一致性，防止每个项目都带着自己的“也许能跑”搬进来。

**Gem 与包边界** ---- 掌握 gemspec、版本、文件、依赖、入口和发布制品

**Bundler** ---- 理解 Gemfile、锁文件、解析、组、平台、路径依赖和部署安装

**加载机制** ---- 区分 require、load、autoload、$LOAD_PATH 和常量查找

**代码风格与工具** ---- 建立 RuboCop、格式化、静态分析、类型工具和提交检查

**版本与兼容** ---- 关注 Ruby 版本、Gems、弃用、原生扩展和平台矩阵

**供应链安全** ---- 管理来源、锁定、审计、秘密、安装脚本和发布权限

**重点解释** ---- 这一站要能让项目在新机器上可重复安装、可检查、可发布，不靠某个开发者的本地魔法

## 第七站：线程、Fiber、Ractor 与运行时

Ruby 的并发家族各有性格：Thread 共享房间，Fiber 会礼貌暂停，Ractor 更强调隔离；它们都能同时做事，但不保证替你解决所有等待。

**线程模型** ---- 理解 Thread、GIL、I/O、线程安全、共享状态、锁和线程局部变量

**Fiber 与事件驱动** ---- 掌握协作式切换、调度、异步 I/O、暂停/恢复和生命周期

**Ractor** ---- 了解隔离、可分享对象、消息传递、限制和适用场景

**队列与同步** ---- 学习 Queue、Mutex、ConditionVariable、Monitor 和生产者消费者

**任务取消与关闭** ---- 设计停止信号、超时、资源释放、异常传播和线程池边界

**内存与 GC** ---- 认识对象分配、标记清除、写屏障、堆、符号、字符串和内存增长

**重点解释** ---- 这一站通关是能按 I/O、CPU、共享状态和隔离要求选择并发模型，并知道 Ruby 运行时在哪些地方会帮忙、哪些地方不会

## 第八站：性能、测试与安全

Ruby 很擅长让人快速表达想法，性能和安全则要求它把想法说得更具体。测量、测试和边界是让灵感平安抵达生产的护栏。

**性能分析** ---- 使用 benchmark、stackprof、memory_profiler、对象统计、GC 观测和火焰图

**缓存与分配** ---- 关注字符串、数组、闭包、元编程、查询、缓存和序列化成本

**测试体系** ---- 掌握 Minitest、RSpec、Mock、集成、请求、数据库、契约和端到端测试

**属性与模糊测试** ---- 了解随机输入、边界生成、回归和解析器测试

**Web 安全** ---- 防范注入、XSS、CSRF、命令、路径、SSRF、反序列化和秘密泄露

**可观测性** ---- 建立结构化日志、指标、追踪、错误监控和告警

**重点解释** ---- 这一站要能用证据定位性能问题，用测试锁住行为，用边界阻止输入和依赖制造事故

## 第九站：Rails 与生产应用

Rails 像一位很热情的管家：路由、模型、迁移、视图、任务和约定都替你安排了。管家越能干，你越要知道钥匙放在哪里。

**Rails 基础** ---- 了解路由、控制器、模型、视图、约定优于配置和请求生命周期

**Active Record** ---- 掌握关联、查询、事务、迁移、N+1、锁和查询计划

**后台任务与实时** ---- 认识 Active Job、队列、重试、幂等、Action Cable 和连接生命周期

**缓存与部署** ---- 理解页面/片段缓存、Redis、资产、进程、容器和健康检查

**安全与升级** ---- 关注认证、授权、CSRF、参数、依赖、迁移和版本升级

**架构边界** ---- 学习服务对象、领域模块、事件、模块化和避免巨型模型

**重点解释** ---- 这一站通关是能用 Rails 快速交付，同时解释约定、回调、查询、任务和生产边界

## 学习路径建议：从对象到产品

**第一阶段：语言本体** ---- 完成第一至第三站，掌握对象、作用域、方法、块、枚举和数据

**第二阶段：动态能力** ---- 完成第四至第六站，理解元编程、资源、Gems 和项目边界

**第三阶段：运行时与质量** ---- 完成第七至第八站，掌握并发、内存、性能、测试和安全

**第四阶段：Rails 闭环** ---- 完成第九站，交付一个可观察、可测试、可升级的应用

## 通关标准

**语言通关** ---- 能解释对象模型、方法查找、块、闭包、Enumerable、异常和编码

**动态通关** ---- 能读懂反射、单例类、钩子和 DSL，知道动态能力的代价

**运行时通关** ---- 能解释 Thread、Fiber、Ractor、GC、分配和性能工具

**工程通关** ---- 能完成 Gems、Bundler、测试、安全、观测和部署

## 结语

Ruby 像一位会讲故事的工程师：它希望代码读起来有节奏，也愿意给你足够自由。但故事要能让别人接着讲，必须有章节、角色和边界。让 Ruby 保持优雅，也让项目保持可解释，这才是它真正迷人的地方。
