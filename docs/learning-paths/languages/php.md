# PHP 学习路线

PHP 是 Web 世界那位从早期互联网一路工作到今天的老员工：它见过模板、面向对象、Composer、现代类型、异步运行时和容器化，也保留着不少历史包袱。它不怕快速交付，怕的是我们把旧习惯当成永恒真理。

这份路线是 **通用基础 → 编程语言 → PHP** 的独立学习地图，覆盖语言、Zend 引擎、Web 边界、Composer、测试、性能、安全和现代生态，不是函数手册。

**适合谁** ---- 想做 Web 后端、内容系统、电子商务、Laravel/Symfony、WordPress 扩展或需要维护 PHP 老项目并逐步现代化的开发者

**先记住一件事** ---- PHP 能让页面很快出现，也能让隐式转换很快制造事故；现代 PHP 的第一原则是显式、类型化、可测试、可观测

**推荐总顺序** ---- 运行环境与语法 → 类型与数据 → 函数与作用域 → OOP/trait/枚举 → 异常与 I/O → Web 运行模型 → Composer → 数据库与安全 → 性能与异步 → 工程与框架

**本页怎么用** ---- 先学现代语言和运行时，再进入 Laravel、Symfony 或其他方向；读旧代码时要理解历史，写新代码时要有边界。

## 第一站：PHP、Zend 与语法地基

PHP 的解释器像一位经验丰富的剧务：脚本来了就安排执行，变量、请求和输出都能很快到位，但配置与版本要先对上暗号。

**运行方式** ---- 区分 CLI、FPM、Apache 模块、Web 请求生命周期、脚本结束和常驻进程

**变量与类型** ---- 掌握弱/强类型边界、类型声明、类型转换、严格模式、常量、作用域和引用变量

**表达式与控制流** ---- 覆盖比较、松散/严格相等、真假值、运算符、条件、循环、match 和错误抑制边界

**字符串与数组** ---- 理解字符串编码、插值、字节、PHP array 的有序哈希表本质、键转换和拷贝语义

**函数与参数** ---- 学习默认值、可变参数、命名参数、返回类型、联合/交集类型、闭包和一等函数

**错误报告与配置** ---- 认识 php.ini、错误级别、display/log、环境差异和生产配置

**重点解释** ---- 这一站通关是能解释请求、脚本、变量、array、类型转换和错误输出如何一起工作

## 第二站：对象、命名空间与现代类型

PHP 的 class 们以前比较随性，后来逐渐学会穿校服：命名空间负责住址，接口负责合同，枚举和 readonly 负责把状态管得更严。

**类与对象** ---- 掌握属性、方法、构造器、析构器、可见性、静态成员和对象身份

**继承与接口** ---- 理解 extends、implements、抽象类、接口、重写、final 和组合取舍

**trait 与复用** ---- 学习 trait、冲突解决、别名、状态共享和过度复用风险

**命名空间与自动加载** ---- 掌握命名空间、use、别名、全限定名、PSR-4 和包边界

**类型系统** ---- 认识标量、联合、交集、可空、mixed、never、static、返回协变和参数逆变

**枚举与 readonly** ---- 学习 backed enum、状态建模、readonly 属性/类、值对象和不可变边界

**属性与元编程** ---- 了解 attributes、反射、魔术方法、动态属性弃用和显式设计

**重点解释** ---- 这一站要能用现代类型和对象边界约束业务状态，知道历史灵活性什么时候已经变成风险

## 第三站：函数、闭包、迭代器与生成器

PHP 的函数可以闭包、可以捕获变量、可以暂停产出数据。生成器尤其像一位节省体力的快递员，一次送一件，不会把整栋仓库扛上车。

**闭包与捕获** ---- 理解 lexical scope、按值/按引用捕获、this、静态变量和生命周期

**可调用对象** ---- 掌握 callable、Closure、匿名类、回调、参数解包和高阶函数

**迭代器协议** ---- 学习 Iterator、IteratorAggregate、Traversable、内部指针和消费边界

**生成器** ---- 理解 yield、暂停/恢复、yield from、返回值、异常和流式处理

**数组函数与惰性** ---- 认识 map/filter/reduce、排序回调、引用陷阱、复制和大数据集成本

**属性与反射回调** ---- 了解动态调用、反射签名、参数绑定和框架依赖注入入口

**重点解释** ---- 这一站通关是能解释回调如何捕获状态、生成器何时执行、数据何时被复制或物化

## 第四站：异常、资源与序列化

错误会以异常、错误、警告或日志的形式来敲门，文件和网络资源则要求你记得关门。现代 PHP 不能把所有坏消息都改名叫“notice”。

**Throwable 体系** ---- 掌握 Error、Exception、Throwable、错误转异常、捕获范围和自定义异常

**异常链与清理** ---- 学习 try/catch/finally、嵌套、重新抛出、上下文和资源释放

**文件与流** ---- 认识 streams、包装器、上下文、缓冲、编码、临时文件和大文件处理

**JSON 与序列化** ---- 理解 JSON 类型边界、日期、精度、对象序列化、版本和不可信数据

**进程与命令** ---- 了解 CLI、子进程、参数、环境变量、退出码、shell 边界和命令注入

**日志与错误处理** ---- 建立级别、结构化字段、追踪 ID、脱敏、生产错误页和告警

**重点解释** ---- 这一站要能让异常、文件、进程和序列化在失败路径上也可解释、可清理、可恢复

## 第五站：Web 请求、Session 与应用边界

PHP 很擅长接住 Web 请求，但请求是短暂访客，状态、连接和缓存却可能住得很久。应用要学会分清谁是访客、谁是房客、谁有钥匙。

**HTTP 与请求生命周期** ---- 掌握方法、状态码、Header、Body、Cookie、上传、响应、缓存和超时

**SAPI 与 FPM** ---- 理解 Web Server、FPM、工作进程、进程模型、共享状态、优雅重启和慢请求

**Session 与 Cookie** ---- 学习会话存储、固定会话、过期、轮换、SameSite、Secure 和 HttpOnly

**路由与中间件** ---- 了解路由匹配、请求管线、中间件顺序、异常边界和依赖注入

**输入输出校验** ---- 覆盖表单、JSON、文件、类型、长度、分页、响应序列化和敏感字段

**缓存与队列预告** ---- 认识 opcode 缓存、应用缓存、共享缓存、失效和后台任务

**重点解释** ---- 这一站通关是能从 Web Server 到 PHP 工作进程再到响应画出请求链，并为状态和资源安排归宿

## 第六站：Composer、包生态与工程化

Composer 是 PHP 项目的采购经理和交通警察：它负责找依赖、锁版本、自动加载，还要提醒大家不要把一堆同名包请进同一个会议室。

**依赖声明与解析** ---- 掌握 package 元数据、版本约束、传递依赖、平台包、可选依赖和锁文件

**自动加载** ---- 理解 PSR-4、类映射、文件自动加载、初始化副作用和包边界

**PSR 与互操作** ---- 认识 PSR-1/4/7/11/12/15/18 等规范的角色和实现边界

**发布与私有源** ---- 了解 Packagist、私有仓库、制品、版本、弃用和供应链

**静态分析与格式** ---- 建立 PHPStan/Psalm、PHP-CS-Fixer、Rector 和 CI 检查

**框架装配** ---- 理解容器、服务提供者、配置、事件、命令和框架启动

**重点解释** ---- 这一站要能让项目在另一台机器上可重复安装、可检查、可升级，而不是依赖某个开发者电脑里的神秘缓存

## 第七站：数据库、事务与安全

数据库不会因为 PHP 的数组很灵活就放松约束，安全门卫也不会因为你使用了框架就自动替你检查每个输入。

**PDO 与数据库访问** ---- 掌握连接、预处理、参数绑定、事务、错误模式和连接生命周期

**ORM 与查询边界** ---- 了解模型、关联、懒加载、N+1、查询构建、原生 SQL 和迁移

**事务与并发** ---- 理解提交、回滚、隔离、锁、死锁、幂等和重试

**认证与授权** ---- 区分密码哈希、Session、Token、OAuth、角色、对象权限和多租户

**Web 攻击面** ---- 防范 XSS、CSRF、SQL 注入、命令、路径、SSRF、文件上传和反序列化

**秘密与依赖安全** ---- 管理密钥、环境变量、日志、依赖漏洞、锁文件和最小权限

**重点解释** ---- 这一站通关是能把数据约束、应用权限和输入输出安全连起来，不把隐藏按钮当成授权

## 第八站：性能、常驻进程与异步

传统 PHP 请求结束后可以把房间收拾干净，常驻进程则会留下来继续工作；这会减少启动成本，也会让全局状态和内存泄漏开始认真发言。

**Zend 执行与 OPcache** ---- 了解 opcode、预加载、缓存失效、JIT 方向和版本差异

**FPM 性能** ---- 分析工作进程、并发、慢请求、进程上限、内存和队列等待

**常驻应用边界** ---- 认识 RoadRunner、Swoole、FrankenPHP 等常驻模型的状态、清理和兼容问题

**Fibers 与异步生态** ---- 理解 Fiber、事件循环、协作式暂停、ReactPHP、Amp 和异步 I/O

**缓存与性能剖析** ---- 使用基准、Profiler、火焰图、查询计划、缓存命中和尾延迟

**资源与故障** ---- 关注连接池、文件句柄、内存、超时、重试、限流和优雅关闭

**重点解释** ---- 这一站通关是能判断性能瓶颈属于 PHP、FPM、数据库、网络还是外部依赖，并知道常驻进程多背了哪些责任

## 第九站：测试、发布与现代生态

PHP 项目要从“页面能打开”成长为“服务能交付”，需要测试、构建、监控和回滚一起上班。单元测试不是装饰，是给未来的自己留的护栏。

**测试** ---- 掌握 PHPUnit、Pest、Mock、集成、HTTP、数据库、契约和端到端测试

**属性与模糊测试** ---- 了解边界生成、随机输入、回归样本和安全输入测试

**框架方向** ---- 进入 Laravel、Symfony、Slim、WordPress 扩展或 API 开发，按产品和团队选择

**容器与部署** ---- 掌握 PHP-FPM、Nginx、CLI worker、容器、健康检查、迁移和信号

**观测与恢复** ---- 建立日志、指标、追踪、告警、备份、回滚和事故记录

**现代化迁移** ---- 规划旧代码类型化、依赖升级、测试补齐、模块拆分和兼容窗口

**重点解释** ---- 这一站的目标是让 PHP 应用可测试、可观察、可升级、可回滚，而不是只在浏览器里保持微笑

## 学习路径建议：从脚本到服务

**第一阶段：语言现代化** ---- 完成第一至第四站，掌握类型、对象、闭包、生成器、异常和资源

**第二阶段：Web 与依赖** ---- 完成第五至第七站，理解请求、Composer、数据库、认证和安全

**第三阶段：运行时与质量** ---- 完成第八至第九站，把性能、常驻、异步、测试和发布放回生产

**第四阶段：框架闭环** ---- 选择 Laravel、Symfony 或其他方向完成真实应用

## 通关标准

**语言通关** ---- 能解释类型转换、array、闭包、生成器、对象、trait、枚举和异常

**Web 通关** ---- 能画出请求、FPM、Session、数据库和响应的边界

**工程通关** ---- 能使用 Composer、静态分析、测试、日志、部署和安全检查

**运行时通关** ---- 能解释 OPcache、常驻进程、并发、缓存、I/O 和性能瓶颈

## 结语

PHP 是一位经历丰富的老员工：它见过很多时代，也愿意继续学习新规矩。你可以感谢它交付速度快，但不要让它替你做隐式决定。现代类型、清晰边界、可靠测试和认真部署，会让这位老员工重新穿上合身的工作服。
