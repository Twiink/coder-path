# 氪金功能屋

记录各种实用功能的实现方案，包括第三方服务集成、常用功能开发和最佳实践。

## 板块特点

- **完整方案**：从接入到部署的完整实现
- **代码示例**：可直接使用的代码片段
- **注意事项**：开发中的坑点和注意事项
- **最佳实践**：业界公认的最佳实践方案

## 功能分类

### 第三方集成

各类第三方服务的接入实现。

#### 支付集成
- [微信支付](/features/integrations/wechat-pay) - 公众号支付、小程序支付、H5 支付
- [支付宝支付](/features/integrations/alipay) - 网页支付、手机网站支付、APP 支付

**实现要点：**
- 签名验证机制
- 异步通知处理
- 订单状态同步
- 退款处理流程
- 安全防护措施

#### 消息通知
- [短信服务](/features/integrations/sms) - 阿里云短信、腾讯云短信
- [邮件服务](/features/integrations/email) - SMTP、SendGrid、阿里云邮件

**实现要点：**
- 模板管理
- 发送队列
- 失败重试
- 发送记录
- 频率限制

#### 文件存储
- [OSS 对象存储](/features/integrations/oss) - 阿里云 OSS、腾讯云 COS、七牛云

**实现要点：**
- 文件上传策略
- 访问权限控制
- CDN 加速配置
- 图片处理服务
- 大文件分片上传
