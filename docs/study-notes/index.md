# 技能书

这里汇集了各种技术栈的学习笔记，记录技术要点、核心概念和实用技巧。

## 笔记分类

### 前端技术

#### JavaScript
- [JavaScript 基础知识](/study-notes/javascript/) - 语法、数据类型、函数、对象
- 异步编程 - Promise、async/await
- ES6+ 新特性
- 原型链与继承
- 闭包与作用域

#### TypeScript
- [TypeScript 基础知识](/study-notes/typescript/) - 类型系统、接口、泛型
- 高级类型
- 装饰器
- 命名空间与模块

#### Vue
- [Vue 基础知识](/study-notes/vue/) - 组件、指令、响应式原理
- Vue Router
- Pinia/Vuex 状态管理
- Composition API
- 性能优化

#### React
- [React 基础知识](/study-notes/react/) - JSX、组件、Hooks
- Redux/MobX 状态管理
- React Router
- 性能优化
- 服务端渲染 (SSR)

### 后端技术

- [Django 基础知识](/study-notes/django/) - MTV 架构、ORM、中间件
- Django REST Framework
- 认证与权限
- 数据库优化
- 缓存策略

#### Node.js
- [Node.js 基础知识](/study-notes/nodejs/) - 模块系统、事件循环
- Express/Koa 框架
- 数据库操作
- 性能优化
- 微服务架构

### 数据库

## 笔记特点

- **实用为主**：聚焦实际开发中的高频知识点
- **代码示例**：每个概念都配有可运行的代码示例
- **最佳实践**：总结业界公认的最佳实践
- **常见陷阱**：标注容易踩坑的地方

## 笔记结构

每篇笔记通常包含以下部分：

1. **概述**：技术简介和应用场景
2. **核心概念**：关键知识点详解
3. **代码示例**：实际可运行的代码
4. **最佳实践**：推荐的使用方式
5. **常见问题**：FAQ 和解决方案
6. **参考资料**：官方文档和优质资源链接

## 如何使用笔记

1. **快速查阅**：通过搜索功能快速定位知识点
2. **系统学习**：按照分类目录系统学习某个技术栈
3. **实践验证**：复制代码示例到本地运行验证
4. **持续更新**：笔记会随着技术发展持续更新
